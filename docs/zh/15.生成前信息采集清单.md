# 生成前信息采集清单

本页用于**客户提出需求之后、动手生成代码之前**的信息采集与确认：无论人工开发，还是把需求交给 AI 助手（Agent），都建议先按本清单逐项确认，避免默认假设（写错语言、取错环境的库、有真机却连不上）。

::: tip 怎么用

- **★ 必问项**：售前 / 对接人逐条问客户并填入「填写」栏；
- **AI 助手（Agent）**：先问再生成，缺项不要猜；
- 配套阅读：[Agent 开发指引](./13.Agent%20开发指引.md)（§2「动手前先问清楚」）· [编译与验证指南](./14.编译与验证指南.md)（无真机时的三级验证）。

:::

## 1. 语言与编译环境

| 项目 | 关键说明 | 填写 |
| --- | --- | --- |
| ★ 开发语言：C++ / C# / Python | 三语言各有「快速开始」与对应库 | |
| ★ 编译环境（C++ 时）：MinGW(Qt) / MSVC(VS) / Linux GCC | 库按环境区分、**不可混用**；Linux 注意 gcc-4 / gcc-9 库与编译器配套（见 [Linux 环境](./04.上位机/01.C++/01.文档/01.环境搭建/03.Linux%20环境.md)） | |
| （Python 时）解释器版本：3.10 x64（Windows）/ 3.8（Linux） | 官方扩展库按此预编译，**其他版本无法加载**（ImportError）；安装方法见[下载页](./12.相关下载.md) | |
| 上位机运行平台：Windows x64 / Linux x64 | 决定取哪套库、动态库加载方式 | |

## 2. 版本匹配（防「连不上 / 跑不起来」）

## 4. 机器人本体（影响接口选择）

| 项目 | 关键说明 | 填写 |
| --- | --- | --- |
| 机器人数量（请客户选择）：单机器人 / 双臂机器人 / 其他数目 | 双臂（多机器人）使用 `_robot` 多机接口，写法与单机不同；选择“其他数目”时请注明具体数量 | |
| 轴数 | **默认按 6 轴，无需询问**；仅当客户明确说明轴数（4 / 7 …）时，按其说明 | 默认 6 轴 |
| 外部轴 | **默认没有，无需询问**；仅当客户明确说明带外部轴时才按外部轴处理 | 默认无 |
| 是否有仿真环境 | 无真机时可用于验证（可选；没有则按编译级验证） | |

## 6. 交付形式与验证

| 项目 | 选项 | 选择 |
| --- | --- | --- |
| 交付形式 | 源码 / 可编译工程（VS、Qt、Makefile）/ 可运行的示例程序 | |
| 程序形态 | 控制台示例 / 带界面（Qt、WinForms） | |
| 验证方式 | 真机联调 / 无硬件三级验证（L1 语法 → L2 编译链接 → L3 运行自检） | |

## 7. 安全确认（涉及真实运动时，运行前必查）

- [ ] 工作空间内无人员与障碍物；急停按钮可用且在可触及范围内
- [ ] 首次运行使用低速；已核对轴号 / 方向 / 目标点位 / IO 端口
- [ ] 生成的代码保留安全警告（Agent 默认遵守）

| 项 | 内容 |

## 生成后默认约定（Agent 默认遵守，不必问客户）

- IP / 端口做成可配置项（文件顶部配置或命令行参数）；
- 附「编译与运行说明」；运动类代码必须保留安全提示；
- 函数名以官网接口页 / SDK 头文件为准，不臆造；
- 无真机时，附 L1 / L2 / L3 三级验证步骤。
