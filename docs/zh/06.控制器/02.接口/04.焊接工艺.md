# 二次开发 API（焊接工艺）

本章节介绍控制器侧的焊接工艺控制接口，包括焊接使能、送丝/退丝、送气、手动电焊、焊机故障复位、焊接状态查询以及多重多道焊参数读取。

> 这些接口直接控制焊机与送丝机构，属于会产生实际动作的工艺接口，调用前请确认工作环境安全。

## 函数索引

| 函数 | 说明 |
|------|------|
| NRC_WeldEnabled | 焊接使能 |
| NRC_SpotWeldOp | 手动电焊 |
| NRC_FeedWire / NRC_ReturnWire | 送丝 / 退丝 |
| NRC_Aspirated | 送气 |
| NRC_WeldFaultReset | 焊机故障复位 |
| NRC_WeldState | 焊接状态查询 |
| NRC_GetMultipassWeldParm | 获取多重多道焊接参数 |

## 详细接口文档

### NRC_WeldEnabled

| 函数原型 | int NRC_WeldEnabled(int stats); |
| --- | --- |
| 功能描述 | 焊接使能。 |
| 参数说明 | 输入参数：<br>stats 1-开启焊接使能 0-关闭焊接使能 |
| 返回值 | 0：函数调用成功返回<br>-101：无效的输入参数返回<br>-102：目标对象不存在，一般出现在系统初始化未完成时，调用其他函数时可能返回该值返回<br>-103：目标对象当前处于不可操作状态返回 |
| 备注说明 | 关闭焊接使能后，其余焊接操作接口不再生效。 |

## 数据结构

### NRC_WeldStateParam

| 字段 | 类型 | 说明 |
|------|------|------|
| pistolSwitch | int | 焊枪开关 |
| arcingSuccess | int | 引弧成功 |
| handWireFeed | int | 手动送丝 |
| weldCurrent | double | 焊接电流 |
| weldVoltage | double | 焊接电压 |
| runTime | double | 焊接时间 |
| dutyRatio | double | 焊接占空比 |

### NRC_ArcParam

| 字段 | 类型 | 说明 |
|------|------|------|
| weldVoltage | double | 焊接电压，范围 [-1000, 1000] V |
| weldCurrent | double | 焊接电流，范围 [0, 1000] A |
| arconUseParam | bool | 是否使用起弧参数 |
| arconCurrent | double | 起弧电流，范围 [0, 1000] A |
| arconVoltage | double | 起弧电压，范围 [-1000, 1000] V |
| arconTime | double | 起弧时间，范围 [0, 5] s |
| arconRampEnable | bool | 是否使能起弧渐变 |
| arconRampMode | int | 起弧方式，0-时间渐变 |
| arconRampTime | double | 起弧渐变时间，范围 [0, 100000] ms |
| arcoffUseParam | bool | 是否使用收弧参数 |
| arcoffCurrent | double | 收弧电流，范围 [0, 1000] A |
| arcoffVoltage | double | 收弧电压，范围 [-1000, 1000] V |

| 字段 | 类型 | 说明 |
|------|------|------|

| initialDir | int | 初始方向 |

### NRC_WeldOperationType

焊接操作类型枚举，用于标识当前焊接操作。

| 枚举值 | 值 | 说明 |
|--------|-----|------|
| NRC_WELD_ENABLED_OP | 1 | 焊接使能 |
| NRC_ARCON_MODE | 2 | 起弧模式 |
| NRC_SPOT_WELD_OP | 3 | 手动电焊 |
| NRC_FEED_WIRE_OP | 4 | 送丝 |
| NRC_RETURN_WIRE_OP | 5 | 退丝 |
| NRC_ASPIRATED_OP | 6 | 送气 |
| NRC_WELD_FAULT_RESET | 7 | 焊机故障复位 |

## 典型调用流程

```cpp
#include "nrcAPI.h"

int main()
{
    NRC_StartController();
    NRC_GetControlInitComplete();

    // 焊接使能并送气
    NRC_WeldEnabled(1);
    NRC_Aspirated(1);

    // 送丝
    NRC_FeedWire(1);
    NRC_FeedWire(0);

    // 查询焊接状态
    NRC_WeldStateParam state;
    NRC_WeldState(state);

    // 结束：停止送气并关闭焊接使能
    NRC_Aspirated(0);
    NRC_WeldEnabled(0);
    return 0;
}
```

## 注意事项

- 焊接相关接口会驱动焊机与送丝机构产生实际动作，调试时请保持安全距离。
- `NRC_GetMultipassWeldParm` 只读取工艺参数，不触发焊接动作。
- 焊接工艺参数（起弧/收弧、摆焊）通过示教器或工艺配置文件设置，本节接口只负责使能与状态查询。
