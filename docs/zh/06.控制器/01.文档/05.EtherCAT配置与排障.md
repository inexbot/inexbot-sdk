# EtherCAT 配置与排障

现场总线问题里，最常见的三类是：**从站扫不到**、**能扫到但映射失败**、**掉 OP（运行态）**。本页给出排查顺序，把「查哪一层」先定下来，再往下钻。

> 本页的排查流程来自现场归纳；ENI 文件与 PDO 字段的具体定义以你的控制器版本与从站 ESI 文件为准。

## 一、先分清是三件事

| 现象 | 属于 | 先查 |
|------|------|------|
| 从站列表空的 / 少几个 | 物理层或主站启动 | 网线、分支器、主站是否启动 |
| 全部扫到，但轴不动 / 报映射错 | 配置层 | ENI 与从站是否匹配、PDO 偏移 |
| 起来后过一会儿掉 OP | 运行层 | 线序/终端电阻/EMC/看门狗 |

## 二、启动顺序

1. 控制器上电，**主站先完成初始化**；
2. 再启动控制程序 / 上位机连接（不要在上位机连上后反复重启主站）；
3. 从站进入 OP 后再开始下发运动指令。

> 现场反复出现「主站与控制程序启动顺序颠倒 → 从站进不了 OP」的情况，建议把顺序写进现场作业指导书。

## 三、从站扫不到

| 可能原因 | 验证方法 |
|----------|----------|
| 网线/接头问题 | 看网口指示灯；换一根已知良好的线 |
| 分支器/交换机未上电或端口坏 | 换端口试；把从站直连主站试（排除分支器） |
| 分支器级联顺序与 ENI 不一致 | 按 ENI 拓扑顺序恢复接线 |
| 从站地址（alias）冲突 | 逐个断开，定位重复地址的从站 |
| 从站固件/ESI 版本与 ENI 不符 | 核对从站型号与版本号 |
| 只识别到 IO 一个从站 | 典型是 ENI 与实物拓扑不一致，或中间某个从站异常拖住了扫描 |

## 四、能扫到但映射失败

| 可能原因 | 验证方法 |
|----------|----------|
| ENI 的从站型号/版本与实际不一致 | 对照 ESI 文件里的 Vendor ID / Product Code / Revision |
| PDO 长度或偏移写错 | 对照从站手册的 PDO 映射表逐项核 |
| 输入/输出方向搞反 | 看目标值与实际值是否互为镜像 |
| 该从站不支持 ENI 里配置的 PDO | 换用从站支持的 PDO 组合 |

## 五、掉 OP

| 可能原因 | 验证方法 |
|----------|----------|
| 线缆/接头接触不良 | 轻拉网线观察是否掉站；换线复测 |
| 终端电阻/拓扑问题 | 按 EtherCAT 拓扑规则检查末端与分支 |
| 强电干扰 | 动力线与信号线分开走线，必要时加磁环 |
| 某从站看门狗超时 | 查该从站的通信错误计数 |
| 主站周期与从站能力不匹配 | 降低主站周期或减少从站数量验证 |

## 六、回零后目标值/实际值不一致

排查顺序：

1. 先确认**回零本身成功**（回零状态位、回零完成标志）；
2. 再读该轴的目标 PDO 与实际位置 PDO，看差值是否恒定：
   - 差值**恒定** → 多半是零点偏置/减速比配置问题；
   - 差值**随时间变大** → 跟随误差问题（增益、限速、机械卡阻）；
3. 换一根轴驱动同一段轨迹，判断是「该从站」还是「全局配置」问题。

## 七、换板 / 换固件后的核查

| 变更 | 必须重新确认 |
|------|--------------|
| 换 IO 板型号 | `get_io_type` 的端口数；ENI 里的从站配置 |
| 换伺服/驱动器 | ESI 文件版本、PDO 映射、编码器位数 |
| 升级控制器固件 | ENI 是否仍兼容；从站列表是否齐全 |
| 换控制器整机 | 导入配置后**断电 20 秒**再上电（现场经验：直接重启常识别不全） |
