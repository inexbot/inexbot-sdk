# 错误码表

本页汇总**接口返回值**与**控制器上报消息码**两套体系的入口。两者独立：接口返回值说明「这次调用成不成功」，消息码说明「控制器内部发生了什么」。

## 两套码，别混用

| 体系 | 谁产生 | 典型值 | 在哪看 |
| ---- | ------ | ------ | ------ |
| 上位机 SDK 返回值 `Result` | 上位机库本地判定 + 控制器应答 | `0`、`-1` ~ `-6` | 接口调用的返回值 |
| 控制器 SDK 返回值 | `NRC_*` 接口 | `0`、`-101`、`-102`、`-103` | 接口调用的返回值 |
| **控制器上报消息码** | 控制器运行期主动上报 | `4097`、`9249` 等 4~5 位 | 消息回调 / 界面弹窗 |

接口返回成功，不代表控制器没有上报消息——两者要分开判断。

:::

## 控制器 SDK 返回值

`NRC_*` 接口的返回值约定（以接口页的「返回值」栏为准）：

| 值 | 含义 | 常见原因 |
| -- | ---- | -------- |
| 0 | 成功 | — |
| -101 | 无效的输入参数 | 参数越界、指针为空、索引非法 |
| -102 | 目标对象不存在 | 系统初始化未完成即调用；机器人/轴号/工艺号不存在 |
| -103 | 目标对象当前处于不可操作状态 | 模式不符、未上电、正在运行、前置条件未满足 |

各接口的具体前置条件见[接口说明](../02.接口/index.md)。

## 上位机 SDK 返回值

`Result` 枚举（`nrc_define.h`）与按接口族的 `-4` 常见原因，见 [C++ · 错误码表](../../04.上位机/01.C++/04.参考/错误码表.md)。C# 与 Python 的返回值语义相同，仅在语言封装上有差异。
