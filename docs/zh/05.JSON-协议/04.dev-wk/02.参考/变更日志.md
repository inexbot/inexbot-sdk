本页记录 dev-wk（RTL 25.02.0）通讯协议文档的增补与修订。

## 2026-11-23 协议补齐

依据控制器源码整理的《RTL-25 控制器 6000/6001/7000 端口通讯协议》（RTL 25.02.0，代码基线 `b72eb2ce6`，共 1368 条命令字）比对后补齐文档。

比对口径：只补「源码中有实际收发实现」的命令；源码中「定义但未使用」的命令不写入文档。
