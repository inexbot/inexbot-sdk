# 喷涂工艺

本章介绍 RTL-24.03 协议中喷涂工艺（0x86xx）的通讯命令，包括模拟量组、数字参数、喷涂顺序、喷涂轨迹、手动操作以及当前模拟量与出油时间。

> 所有命令均需携带 `robot`（机器人号）；`ID` 为喷涂工艺号 / 模拟量组编号。

## 喷涂模拟量组

### 上位机设置喷涂模拟量组

**命令字：** `0x8600`

| 参数名 | 类型 | 说明 |
|--------|------|------|
| robot | int | 机器人号，范围[1,4] |
| ID | int | 模拟量组编号 |
| flow | double | 流量 |
| sector | double | 扇面 |
| atom | double | 雾化 |
| Aout.flowAnalogQuantity | int | 流量对应的模拟量输出端口 |
| Aout.secterAnalogQuantity | int | 扇面对应的模拟量输出端口 |
| Aout.atomizationAnalogQuantity | int | 雾化对应的模拟量输出端口 |
| note | string | 注释 |

```json
{
  "robot": 1,
  "ID": 1,
  "flow": 1.0,
  "sector": 1.0,
  "atom": 1.0,
  "Aout": {
    "flowAnalogQuantity": 1,
    "secterAnalogQuantity": 1,
    "atomizationAnalogQuantity": 1
  },
  "note": ""
}
```

### 上位机查询喷涂模拟量组

**命令字：** `0x8601`

| 参数名 | 类型 | 说明 |
|--------|------|------|
| robot | int | 机器人号，范围[1,4] |
| ID | int | 模拟量组编号 |

```json
{
  "robot": 1,
  "ID": 1
}
```

**控制器回复**

**命令字：** `0x8602`

返回字段同 0x8600。

```json
{
  "robot": 1,
  "ID": 1,
  "flow": 1.0,
  "sector": 1.0,
  "atom": 1.0,
  "note": ""
}
```

## 喷涂轨迹

### 上位机设置喷涂轨迹

**命令字：** `0x8609`

| 参数名 | 类型 | 说明 |
|--------|------|------|
| robot | int | 机器人号，范围[1,4] |
| ID | int | 喷涂轨迹编号 |
| type | int | 轨迹类型 |
| kind | int | 类别 |
| layer | int | 层号 |
| append | int | 是否追加 |
| closeGunInTransition | bool | 过渡段是否关枪 |
| custom.segmentSum | int | 自定义段总数 |
| custom.segmentType | int[][] | 各段类型 |
| custom.startPos | double[][] | 各段起始位置 |
| custom.endPos | double[][] | 各段结束位置 |
| custom.middlePos | double[][][] | 各段中间位置 |
| pos | double[][] | 轨迹点位置 |

```json
{
  "robot": 1,
  "ID": 1,
  "type": 1,
  "kind": 1,
  "layer": 1,
  "append": 1,
  "closeGunInTransition": true,
  "custom": {
    "segmentSum": 1,
    "segmentType": [[1]],
    "startPos": [[1.0]],
    "endPos": [[1.0]],
    "middlePos": [[[[1.0]]]]
  },
  "pos": [[[1.0]]]
}
```

### 上位机查询喷涂轨迹

**命令字：** `0x860A`

| 参数名 | 类型 | 说明 |
|--------|------|------|
| robot | int | 机器人号，范围[1,4] |
| ID | int | 喷涂轨迹编号 |

```json
{
  "robot": 1,
  "ID": 1
}
```

**控制器回复**

**命令字：** `0x860B`

返回字段同 0x8609，另以角度形式返回：`custom.startPosDeg`、`custom.endPosDeg`、`custom.middlePosDeg`、`posDeg`。

```json
{
  "robot": 1,
  "ID": 1,
  "kind": 1,
  "layer": 1,
  "append": 1,
  "closeGunInTransition": true,
  "custom": {
    "segmentSum": 1,
    "segmentType": [1],
    "startPos": [],
    "endPos": [],
    "middlePos": [[[]]],
    "middlePosDeg": [[]]
  },
  "pos": [[]],
  "posDeg": []
}
```
