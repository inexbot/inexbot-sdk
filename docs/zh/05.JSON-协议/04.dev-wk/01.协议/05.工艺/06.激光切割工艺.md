# 激光切割工艺

本章介绍 RTL-24.03 协议中激光切割工艺（0x84xx）的通讯命令，包括激光 IO 端口、激光设备参数、模拟量匹配、切割参数、状态查询与手动操作。

> 所有命令均需携带 `robot`（机器人号）与工艺号（切割参数表号、编号等），未在表中列出的字段表示该命令不读写该字段。

## 激光 IO 端口

### 上位机设置激光 IO 端口

**命令字：** `0x8400`

| 参数名 | 类型 | 说明 |
|--------|------|------|
| IO.DO_backMiddle | int | 回中数字输出端口 |
| IO.DO_liftUp | int | 上抬数字输出端口 |
| IO.DO_follow | int | 跟随数字输出端口 |
| IO.DO_lightGate | int | 光闸数字输出端口 |
| IO.DO_aspiration | int | 吹气数字输出端口 |
| IO.DO_capacitance_ | int | 电容标定数字输出端口 |
| IO.DI_liftUpArrival | int | 停靠到位数字输入端口 |
| IO.DI_backMiddleArrival | int | 回中到位数字输入端口 |
| IO.DI_followArrival | int | 跟随到位数字输入端口 |
| IO.DI_perforateArrival | int | 穿孔到位数字输入端口 |
| IO.DI_capacitance_ | int | 电容标定数字输入端口 |
| IO.AO_pressure | int | 气压模拟量输出端口 |
| IO.AO_laserPower | int | 激光功率模拟量输出端口 |
| IO.pwm_port_ | int | 激光功率 PWM 端口：0 无，1 为 1-1，2 为 1-2 |
| shield_enable | bool | 屏蔽使能 |
| shield_time | int | 屏蔽时间 |
| input_port | int | 检查输入端口号 |
| input_value | int | 检查输入值 |

```json
{
  "IO": {
    "DO_backMiddle": 1,
    "DO_liftUp": 1,
    "DO_follow": 1,
    "DO_lightGate": 1,
    "DO_aspiration": 1,
    "DO_capacitance_": 1,
    "DI_liftUpArrival": 1,
    "DI_backMiddleArrival": 1,
    "DI_followArrival": 1,
    "DI_perforateArrival": 1,
    "DI_capacitance_": 1,
    "AO_pressure": 1,
    "AO_laserPower": 1,
    "pwm_port_": 1
  }
}
```

## 激光设备参数

### 上位机设置激光设备

**命令字：** `0x8403`

| 参数名 | 类型 | 说明 |
|--------|------|------|
| equipment.arrivalOutLightMode | int | 出光模式：0 到位出光，1 直接出光 |
| equipment.preAspiratedTime | double | 提前送气时间 |
| equipment.waitLiftUpTime | double | 等待上抬时间 |
| equipment.waitFollowTime | double | 等待跟随时间 |
| equipment.RetreatDistance | double | 回退距离 |
| equipment.delAspiratedMode | int | 关气模式：0 提前关气，1 延后关气 |
| equipment.delAspiratedTime | double | 提前 / 延后关气时间 |
| perforate.time | double | 穿孔时间 |
| perforate.pressure | double | 穿孔压力 |
| perforate.power | int | 穿孔功率 |
| perforate.freq | int | 穿孔频率 |
| perforate.dutyRatio | int | 穿孔占空比 |

```json
{
  "equipment": {
    "arrivalOutLightMode": 1,
    "preAspiratedTime": 1.0,
    "waitLiftUpTime": 1.0,
    "waitFollowTime": 1.0,
    "RetreatDistance": 1.0,
    "delAspiratedMode": 1,
    "delAspiratedTime": 1.0
  },
  "perforate": {
    "time": 1.0,
    "pressure": 1.0,
    "power": 1,
    "freq": 1,
    "dutyRatio": 1
  }
}
```
