# 打磨工艺

本章介绍 RTL-24.03 协议中打磨工艺（0x85xx）的通讯命令。

## 打磨参数

### 上位机设置打磨参数

**命令字：** `0x8500`

| 参数名 | 类型 | 取值范围 | 说明 |
|--------|------|----------|------|
| robot | int | [1,4] | 机器人号 |
| craftID | int | - | 打磨工艺号 |
| polish.toolWear | double | [-100,100] | 刀具磨损补偿量 |
| polish.startToolOffset.X | double | [-1000,1000] | 起始点工具补偿 X |
| polish.startToolOffset.Y | double | [-1000,1000] | 起始点工具补偿 Y |
| polish.startToolOffset.Z | double | [-1000,1000] | 起始点工具补偿 Z |
| polish.endToolOffset.X | double | [-1000,1000] | 结束点工具补偿 X |
| polish.endToolOffset.Y | double | [-1000,1000] | 结束点工具补偿 Y |
| polish.endToolOffset.Z | double | [-1000,1000] | 结束点工具补偿 Z |
| polish.autoFeed.value | double | [-100,100] | 自动进给量 |
| polish.autoFeed.cycle | int | - | 自动进给周期 |

```json
{
  "robot": 1,
  "craftID": 1,
  "polish": {
    "toolWear": 1.0,
    "startToolOffset": {
      "X": 1.0,
      "Y": 1.0,
      "Z": 1.0
    },
    "endToolOffset": {
      "X": 1.0,
      "Y": 1.0,
      "Z": 1.0
    },
    "autoFeed": {
      "value": 1.0,
      "cycle": 1
    }
  }
}
```

### 上位机查询打磨参数

**命令字：** `0x8501`

| 参数名 | 类型 | 取值范围 | 说明 |
|--------|------|----------|------|
| robot | int | [1,4] | 机器人号 |
| craftID | int | - | 打磨工艺号 |

```json
{
  "robot": 1,
  "craftID": 1
}
```

**控制器回复**

**命令字：** `0x8502`

返回字段同 0x8500。

```json
{
  "robot": 1,
  "craftID": 1,
  "polish": {
    "autoFeed": {
      "cycle": 1,
      "value": 1.0
    },
    "endToolOffset": {
      "X": 1.0,
      "Y": 1.0,
      "Z": 1.0
    },
    "startToolOffset": {
      "X": 1.0,
      "Y": 1.0,
      "Z": 1.0
    },
    "toolWear": 1.0
  }
}
```
