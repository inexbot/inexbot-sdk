# 未分类 - 工艺与参数（0x4001–0x7278）

> 焊接设备与焊接参数、码垛相关参数、圆柱相交、全局速度与示教参数、镜像与备份、拖动示教等「未分类」分类的尾段命令。

## 设置电流电压匹配（0x4004–0x4006）

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x4004` | 上位机 → 控制器 | 设置电流电压匹配 |
| `0x4005` | 上位机 → 控制器 | 查询电流电压匹配 |
| `0x4006` | 控制器 → 上位机 | 电流电压匹配应答 |

**请求参数（0x4004）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `current_control.set_voltage[]` | `array<double>` | 设置电压 | [0,10] |
| `current_control.actual_current[]` | `array<double>` | 实际当前 | [0,1000] |
| `voltage_control.set_voltage[]` | `array<double>` | 设置电压 | [0,10] |
| `voltage_control.actual_voltage[]` | `array<double>` | 实际电压 | [-1000,1000] |

```json
{
    "current_control": {
        "set_voltage": [
            1.0
        ],
        "actual_current": [
            1.0
        ]
    },
    "voltage_control": {
        "set_voltage": [
            1.0
        ],
        "actual_voltage": [
            1.0
        ]
    }
}
```

> `0x4005`：该命令的处理器未读取 `rootRecv` 中的字段。

| 参数名 | 类型 | 说明 |

| `voltage_control.actual_voltage[]` | `array<any>` | 实际电压 |

        "set_voltage": [],

    },

        "set_voltage": [],
        "actual_voltage": []
    }
