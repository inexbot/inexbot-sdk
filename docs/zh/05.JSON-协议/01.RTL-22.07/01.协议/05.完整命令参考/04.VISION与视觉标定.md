# VISION 与视觉标定（0x4101–0x4129）

> VISION（19 条）与 vision calibration（13 条）两个分类：视觉参数、视觉调试点位、手势标定、视觉标定参数与标定点位。

## 设置视觉参数（0x4101–0x4103）

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x4101` | 上位机 → 控制器 | 设置视觉参数 |
| `0x4102` | 上位机 → 控制器 | 查询视觉参数 |
| `0x4103` | 控制器 → 上位机 | 视觉参数应答 |

**请求参数（0x4101）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `visionNum` | int | 视觉编号 | [0,98] |
| `vision.protocol.timeOut` | double | 时间输出 | [0,5000] |
| `vision.protocol.addDataNum` | int | 添加数据编号 | [0,10] |
| `vision.trigger.intervals` | double | — | (0,30000] |
| `vision.trigger.duration` | double | 触发方式为IO时的持续触发时间 | (0,10000] |
| `vision.userCoordNum` | int | 用户坐标系编号 | [0,999] |
| `vision.socket.portOne` | int | 端口号单 | [0,65535] |
| `vision.socket.portTwo` | int | 端口号双 | [0,65535] |
| `vision.protocol.hasUCS` | bool | 是否有用户坐标系 | true / false |
| `vision.hasUCS` | bool | 是否有用户坐标系 | true / false |
| `vision.socket.camera_data_type` | int | 相机数据类型 | — |
| `vision.protocol.type` | int | 类型 | — |
| `vision.protocol.addDataInitialPara` | string | 附加数据起始变量 | 字符串 |
| `cameraType` | string | 相机类型 | 字符串 |

```json
{
    "robot": 1,
    "visionNum": 1,
    "vision": {
        "protocol": {
            "timeOut": 1.0,
            "addDataNum": 1,
            "hasUCS": true,
            "type": 1,
            "addDataInitialPara": ""
        },
        "trigger": {
            "intervals": 1.0,
            "duration": 1.0
        },
        "userCoordNum": 1,
        "socket": {
            "portOne": 1,
            "portTwo": 1,
            "camera_data_type": 1
        },
        "hasUCS": true
    },
    "cameraType": ""
}
```

**请求参数（0x4102）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `visionNum` | int | 视觉编号 | [0,98] |

```json
{
    "robot": 1,
    "visionNum": 1
}
```

**应答参数（0x4103）**

| 参数名 | 类型 | 说明 |
|---|---|---|
| `protocol.addDataNum` | int | 添加数据编号 |
| `protocol.addDataInitialPara` | string | 附加数据起始变量 |
| `trigger.duration` | int | 触发方式为IO时的持续触发时间 |
| `socket.IP` | string | — |
| `cameraList` | — | 相机列表 |

```json
{
    "protocol": {
        "addDataNum": 1,
        "addDataInitialPara": ""
    },
    "trigger": {
        "duration": 1
    },
    "socket": {
        "IP": ""
    }
}
```
