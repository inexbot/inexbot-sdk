# TRACK-CONVEYOR - 标定与工具（0x7001–0x7Axx）

> 同步定位器标定与坐标系、同步跟踪、协同、同步编码器参数、20 点/4 点标定、三维鼠标、动力学参数、拖动参数与轨迹、抱闸防压、远程控制。

## 设置同步定位器标定（0x7001–0x7003）

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7001` | 上位机 → 控制器 | 设置同步定位器标定 |
| `0x7002` | 上位机 → 控制器 | 查询同步定位器标定 |
| `0x7003` | 控制器 → 上位机 | 同步定位器标定应答 |

**请求参数（0x7001）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `calibrateNum` | int | 标定编号 | [1,3] |

```json
{
    "calibrateNum": 1
}
```

**请求参数（0x7002）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `pointNum` | int | 点位编号 | [0,19]（同模块同类命令） |
| `syncPositionerNum` | int | 同步定位器编号 | [1,3]（同模块同类命令） |

```json
{
    "pointNum": 1,
    "syncPositionerNum": 1
}
```

**应答参数（0x7003）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `pos[]` | `array<any>` | 位置 | 数组 |
| `pointNum` | int | 点位编号 | — |
| `syncPositionerNum` | int | 同步定位器编号 | [1,3] |

```json
{
    "pos": [],
    "pointNum": 1,
    "syncPositionerNum": 1
}
```
