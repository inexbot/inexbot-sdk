# TRACK-CONVEYOR - 变量与位置（0x5602–0x561E）

| 命令字 | 方向 | 含义 |
|--------|------|------|

**请求参数（0x5602）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |

```json
{
    "robot": 1
}
```

**应答参数（0x5603）**

| 参数名 | 类型 | 说明 |
|---|---|---|
| `robot` | int | 机器人号 |
| `globalPosition[]` | `array<double>` | 全局位置 |

```json
{
    "robot": 1,

        1.0
```
