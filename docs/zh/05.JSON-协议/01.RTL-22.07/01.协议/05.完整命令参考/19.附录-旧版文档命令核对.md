# 附录 - 旧版文档命令核对

本页记录一个已知缺口：**旧版 RTL-22.07 文档里写过、但本[完整命令参考](./index.md)（代码基线 `b4c782169`）未能从源码证实的命令字**。

## 为什么会有缺口

本专区的命令字全集取自 `Teach_Box/Connection/vxSvr_v2.h` 中的 `#define`。若某命令字的定义在其它头文件里，或在 `case` 中直接写数值而没有对应定义，就不会出现在这份底表里。

因此下表中的命令**不代表已被移除**，只代表「本次整理未能从 `vxSvr_v2.h` 证实」。使用前请以真实控制器行为或源码 `cmdParsing.cpp` 为准。
