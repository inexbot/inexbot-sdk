# MSG - 系统与激光（0x4301–0x4561）

> MSG 分类后段：控制器 IP、激光 IO 端口、机器人关节/直线/圆弧运动指令。

## 设置控制器IP（0x4301–0x4303）

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x4301` | 上位机 → 控制器 | 设置控制器IP |
| `0x4302` | 上位机 → 控制器 | 查询控制器IP |
| `0x4303` | 控制器 → 上位机 | 控制器IP应答 |

**请求参数（0x4301）**

| 参数名 | 类型 | 说明 |
|---|---|---|
| `name` | string | 名称 |
| `address` | string | 地址 |
| `gateway` | string | — |
| `dns` | string | — |

```json
{
    "name": "",
    "address": "",
    "gateway": "",
    "dns": ""
}
```

> `0x4302`：该命令的处理器未读取 `rootRecv` 中的字段。

**应答参数（0x4303）**

| 参数名 | 类型 | 说明 |
|---|---|---|
| `num` | uint | 编号/数量 |
| `network[].name` | — | 名称 |
| `network[].address` | — | 地址 |
| `network[].gateway` | — | — |
| `network[].dns` | — | — |

```json
{
    "num": 1,
    "network": [
        {
            "name": {},
            "address": {},
            "gateway": {},
            "dns": {}
        }
    ]
}
```
