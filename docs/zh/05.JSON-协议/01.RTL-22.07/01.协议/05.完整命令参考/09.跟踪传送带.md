# TRACK-CONVEYOR - 跟踪传送带（0x4801–0x483F）

> TRACK-CONVEYOR 分类的跟踪传送带部分：传送带参数、位置检查参数、实时查询、用户坐标系、标定、传感器位置与 GRABGESTURE、WAITPOINT。

## 设置跟踪传送带传送带参数（0x4801–0x4803）

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x4801` | 上位机 → 控制器 | 设置跟踪传送带传送带参数 |
| `0x4802` | 上位机 → 控制器 | 查询跟踪传送带传送带参数 |
| `0x4803` | 控制器 → 上位机 | 跟踪传送带传送带参数应答 |

**请求参数（0x4801）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `conveyorID` | int | 传送带编号 | [1,9] |
| `conveyor.maxEncoderVal` | double | 最大编码器值 | >=1 |
| `conveyor.minEncoderVal` | double | 最小编码器值 | <=0 |
| `conveyor.encoderResolution` | double | 编码器分辨率 | [0.5,10000] |
| `conveyor.userCoord` | int | 用户坐标系 | [1,999] |
| `conveyor.encoderDirection` | int | 编码器方向 | 允许值 -1 / 1 |
| `compensation.time` | double | 时间 | [-10000,10000] |
| `compensation.encoderVal` | double | 编码器值 | [-9999999,9999999] |
| `conveyor.posRecordMode` | int | 0-编码器；1-恒速; 2-伺服 | — |
| `track.height` | int | 高度 | — |
| `track.track_on_run_mode_with_target_overrun` | int | — | — |

```json
{
    "robot": 1,
    "conveyorID": 1,
    "conveyor": {
        "maxEncoderVal": 1.0,
        "minEncoderVal": 1.0,
        "encoderResolution": 1.0,
        "userCoord": 1,
        "encoderDirection": 1,
        "posRecordMode": 1
    },
    "compensation": {
        "time": 1.0,
        "encoderVal": 1.0
    },
    "track": {
        "height": 1,
        "track_on_run_mode_with_target_overrun": 1
    }
}
```

**请求参数（0x4802）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `conveyorID` | int | 传送带编号 | [1,9] |

```json
{
    "robot": 1,
    "conveyorID": 1
}
```

**应答参数（0x4803）**

| 参数名 | 类型 | 说明 |
|---|---|---|
| `conveyor.encoderValue` | — | 编码器值 |
| `conveyor.speed` | double | 速度 |
| `compensation` | double | 补偿 |
| `track.height` | — | 高度 |
| `track.track_on_run_mode_with_target_overrun` | int | — |
| `robot` | int | 机器人号 |
| `conveyorID` | int | 传送带编号 |

```json
{
    "conveyor": {
        "speed": 1.0
    },
    "compensation": 1.0,
    "track": {
        "track_on_run_mode_with_target_overrun": 1
    },
    "robot": 1,
    "conveyorID": 1
}
```
