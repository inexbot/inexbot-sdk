# TRACK-CONVEYOR - 冲压与总线（0x8000–0x8206）

> 新版冲压工艺（工件条件、标志、位置、急停相关）、BUS 类型设置与查询、FINS 配置。

## 冲压设置工件条件（0x8000）

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x8000` | 上位机 → 控制器 | 冲压设置工件条件 |

**请求参数（0x8000）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `prev_device_num` | int | 上一个设备编号 | [1,前站冲床数量) |
| `prev_station_work_condition` | int | 上一个工位工作条件 | — |
| `local_device_num` | int | 本地设备编号 | [1,本机冲床数量) |
| `local_station_work_condition` | int | 本地工位工作条件 | — |
| `fixture_num` | int | 夹具编号 | — |
| `fixture_station_work_condition` | int | 夹具工位工作条件 | — |

```json
{
    "prev_device_num": 1,
    "prev_station_work_condition": 1,
    "local_device_num": 1,
    "local_station_work_condition": 1,
    "fixture_num": 1,
    "fixture_station_work_condition": 1
}
```
