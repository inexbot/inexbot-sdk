# TRACK-CONVEYOR - Modbus 与工艺设备（0x5701–0x6210）

> 外部程序、Modbus 类型/使能/心跳/连接、数据上传、电批参数与状态、控制器时间、Modbus 主站，以及错误/警告/信息类占位命令。

## 设置外部程序（0x5701–0x5703）

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x5701` | 上位机 → 控制器 | 设置外部程序 |
| `0x5702` | 上位机 → 控制器 | 查询外部程序 |
| `0x5703` | 控制器 → 上位机 | 外部程序应答 |

**请求参数（0x5701）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `programid` | int | 程序编号 | [1,1000] |
| `jobname` | `array<string>` | 作业名 | 数组 |

```json
{
    "robot": 1,
    "programid": 1,
    "jobname": [
        ""
    ]
}
```

**请求参数（0x5702）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `startprogramid` | int | 起始程序编号 | — |
| `num` | int | 编号/数量 | — |

```json
{
    "robot": 1,
    "startprogramid": 1,
    "num": 1
}
```

**应答参数（0x5703）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `jobnamelist[]` | `array<string>` | 作业名列表 | 数组 |
| `robot` | int | 机器人号 | — |
| `startprogramid` | int | 起始程序编号 | >=1 |

```json
{
    "jobnamelist": [
        ""
    ],
    "robot": 1,
    "startprogramid": 1
}
```
