# MSG - 消息与码垛（0x4180–0x42xx）

> MSG 分类前段：消息通讯参数、码垛抓手/位置/简易位置/点位调试等。

## 设置消息通讯参数（0x4180–0x4182）

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x4180` | 上位机 → 控制器 | 设置消息通讯参数 |
| `0x4181` | 上位机 → 控制器 | 查询消息通讯参数 |
| `0x4182` | 控制器 → 上位机 | 消息通讯参数应答 |

**请求参数（0x4180）**

| 参数名 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [2,10] |
| `craft` | int | 工艺号 | [1,9] |
| `type` | int | 类型 | [0,1] |
| `server` | — | 相机是服务器，控制器是客户端 | — |
| `client` | — | 客户端 | — |

```json
{
    "robot": 1,
    "craft": 1,
    "type": 1
}
```
