# 完整命令参考（RTL-22.07.69）

本专区按控制器源码逐条整理 6000 / 6001 / 7000 端口的全部命令字与参数，可作为查命令字、查参数、查方向的完整底表。

> 适用版本：RTL 22.07.69（`RTL_VERSION`，见 `h/config/versionNumber.h`）
> 代码基线：`Inexbot_Controller` 仓库 `b4c782169`
> 依据文件：`Teach_Box/Connection/vxSvr_v2.h`、`Teach_Box/Connection/cmdParsing.cpp`、`Teach_Box/Connection/cmddata.cpp`、`src/hostComputerService/hostComputerService.cpp`

## 覆盖范围与统计口径

| 端口 | 命令字数 | 说明 |
|------|----------|------|
| 6000 / 6001 | 970 | 共用同一套命令字与同一个 `cmdParsing()` 分支，本文所有正文页与[附录 A](./17.附录-命令字索引.md)统计的即这 970 条 |
| 7000 | 9 | 上位机服务独立协议，见[7000 上位机服务协议](./16.7000上位机服务.md)，不计入 970 |

970 条的方向分布：上位机 → 控制器 628 条，控制器 → 上位机 331 条，双向 0 条，定义但未使用 11 条。

## 帧格式

三个端口帧格式相同，依据 `Teach_Box/Connection/cmddata.cpp` 的 `CmdData` 实现：

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 2 | 同步头 | 固定 `0x4E66` |
| 2 | 2 | 长度 `len` | 数据区字节数，大端 |
| 4 | 2 | 命令字 `cmd` | 大端 |
| 6 | `len` | 数据区 | JSON 文本或二进制 |
| 6+`len` | 4 | CRC32 | 大端；校验范围为 `len + cmd + data`（即第 2 字节起到数据区结束） |

- 帧总长 = `len + 10`。
- `NET_MSG_MAX_SIZE (2048+128)`：单个命令数据区上限 2176 字节。
- 解析时若前两字节不是 `0x4E66`，丢弃 1 字节后重新同步。
- `checkCRC` 为 false 时跳过 CRC 校验（7000 服务可通过配置关闭）。

## 通用约定

- 处理器解析 JSON 失败时返回 `FMT_ERR_`，参数校验失败时返回 `PARM_ERR_`。
- 6000 / 6001 使用同一个 `switch(cmdNum)` 分派；7000 使用独立的 `HostComputerService::cmdParsing()`。
- 命令字为 2 字节无符号整数，`SET` 写入、`INQUIRE` 查询、`RESPOND` 返回结果，另有控制器主动推送的状态/错误类命令。
- 每个命令族（同一前缀的 SET / INQUIRE / RESPOND）合并展示，参数分别给出。

## 阅读须知

本专区只收录能够从源文件直接证实的结论：

- **方向**：命令字在 `cmdParsing.cpp` 的 `switch(cmdNum)` 中有 `case` 标签，记为控制器**接收**；出现在 `sendCMDAdd()` / `send_cmd_interface()` 等发送调用中，记为控制器**发送**。两处都没有的，标 `—` 并在[附录 B](./18.附录-源码枚举与特殊项.md#b-代码中定义但未使用的命令)说明。
- **应答**：处理器分支体内调用 `sendCMDAdd(Y)` 时，才把 `Y` 记为应答；同一 `case` 内多次发送时按调用点切段，字段只归属其后的那条命令。
- **类型**：只采用直接转换（`asInt` / `asUInt` / `asDouble` / `asBool` / `asString`）、局部变量声明、getter 返回类型、结构体成员声明、配置文件往返、字面量这几种证据；都没有则留 `—`。
- **取值范围**：只采用 `adaptValueRange`、显式比较守卫（含 `||` 逐项拒绝、常量在左的比较）、`switch` 允许值集、`!=` 允许值集、`std::min` / `std::max` 夹取、`fabs` 上下限、局部符号上界这几类证据；都没有则留 `—`。区间来自源码中文注释的标（源码注释），来自同模块同类命令同一字段的标（同模块同类命令）。仅报警但不中断处理的判断不计入取值范围。
- **说明**：优先取源码中文注释，其次按字段名逐词翻译；任一词无中文译名则整条留 `—`。
- **示例 JSON** 仅用于展示字段结构，其中的数值为占位值，不代表取值范围。
