# 示教器与上位机的通讯连接

## 心跳

> **说明：** 不管什么通讯模式，都应设计心跳模式，确保通讯状态正常。上位机定期发送心跳检查包给控制器，并等待控制器回应。客户端收到心跳包后需要回复心跳回应包，包数据为检查包所携带的时间戳。上位机收到回应包后检查数据是否正确。数据不正确或超时为收到回应，则认为连接可能中断。

### 收到心跳

| 属性 | 类型 | 说明 |
|------|------|------|
| time | int | 时间戳 |

**命令字**：`0x1200`

```json
{
  "time": 123
}
```

### 回应心跳

| 属性 | 类型 | 说明 |
|------|------|------|
| time | int | 时间戳 |

**命令字**：`0x1201`

```json
{
  "time": 123
}
```

## 上位机关机

> **说明：** 上位机断开发送

**命令字**：`0x1210`

| 属性 | 类型 | 说明 |
|------|------|------|
| date | - | 无 |

## 上位机开机

> **说明：** 上位机接入恢复通信

**命令字**：`0x1211`

| 属性 | 类型 | 说明 |
|------|------|------|
| date | - | 无 |

## 发送获取心跳

**说明：** 上位机主动向控制器请求心跳。

**命令字**：`0x1202`

| 属性 | 类型 | 说明 |
|------|------|------|
| time | int | 时间戳 |

```json
{
  "time": 123
}
```

**控制器回复**

**命令字**：`0x1203`

- 无需发送数据

## 串口数据发送

> **说明：** 上位机通过控制器的串口向外发送数据

**命令字**：`0x1220`

| 属性 | 类型 | 说明 |
|------|------|------|
| port | int | 串口编号 |
| baud | int | 波特率 |
| len | int | 数据长度 |
| data | int[] | 发送的数据 |

```json
{
  "port": 1,
  "baud": 1,
  "len": 1,
  "data": [1]
}
```

## 查询串口数据

> **说明：** 控制器收到串口数据后主动发送给上位机

**命令字**：`0x1221`

| 属性 | 类型 | 说明 |
|------|------|------|
| data | int[] | 接收到的数据 |
| lenRecv | int | 接收到的数据长度 |

```json
{
  "data": [1],
  "lenRecv": 1
}
```

## 发送指令命令

> **说明：** 上位机发送一条指令文本给控制器执行

**命令字**：`0x1226`

| 属性 | 类型 | 说明 |
|------|------|------|
| command | string | 指令内容 |

```json
{
  "command": ""
}
```

## 通讯版本检查

上位机连接控制器后，通过版本比对判断当前连接程序是否与控制器协议版本匹配。

**命令字**：`0x4305`

| 属性 | 类型 | 说明 |
|------|------|------|
| version | string | 上位机程序使用的通讯协议版本号 |

```json
{
  "version": ""
}
```

**控制器回复**

**命令字**：`0x4306`

| 属性 | 类型 | 说明 |
|------|------|------|
| versionMatch | bool | 版本是否匹配 |
| finishinit | bool | 控制器是否已完成初始化 |

```json
{
  "versionMatch": true,
  "finishinit": true
}
```

## 旧版上位机兼容命令

> **说明：** 上位机版本较低时使用。命令字与新版不同，但功能一一对应，新版上位机不应再使用这些命令。

### 错误代码OLD

**命令字**：`0x2B03`

控制器 → 上位机。

| 属性 | 类型 | 说明 |
|------|------|------|
| robot | int | 机器人号 |
| kind | int | 错误类别 |
| code | int | 错误代码 |
| data | string | 读写的数据内容，最长 16 个字符（32 字节） |

```json
{
  "robot": 1,
  "kind": 1,
  "code": 1,
  "data": ""
}
```

### 版本号查询OLD

**命令字**：`0x3402`

上位机 → 控制器。

| 属性 | 类型 | 说明 |
|------|------|------|
| version | string | 版本 |

```json
{
  "version": ""
}
```

**命令字**：`0x3403`

| 属性 | 类型 | 说明 |

| version | string | 控制器版本 |

| ocmVersion | string | OCM 版本 |

| jobFileVersion | string | 作业文件版本 |
| rtlVersion | string | RTL 版本 |
| configFileVersionMismatch | bool | 配置文件版本是否不匹配 |
| sysClock | string | 系统时钟 |
| xc_one_number.deviceId | uint | 1 号 XC 设备编号 |
| xc_one_number.hw_version | uint | 1 号 XC 硬件版本 |
| xc_one_number.fw_version | uint | 1 号 XC 固件版本 |
| xc_one_number.sdk_version | uint | 1 号 XC SDK 版本 |
| xc_two_number.deviceId | uint | 2 号 XC 设备编号 |
| xc_two_number.hw_version | uint | 2 号 XC 硬件版本 |
| xc_two_number.fw_version | uint | 2 号 XC 固件版本 |
| xc_two_number.drv_version | uint | 2 号 XC 驱动版本 |
| nodka_c1201.deviceId | uint | Nodka C1201 设备编号 |
| nodka_c1201.hw_version | uint | Nodka C1201 硬件版本 |
| nodka_c1201.fw_version | uint | Nodka C1201 固件版本 |
| nodka_c1201.drv_version | uint | Nodka C1201 驱动版本 |
