# 独立轴

## 独立轴参数

### 设置独立轴界面参数

**命令字：** `0x2800`

**参数说明：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| axisNum | int | 轴编号 |
| angularDistanceConversionRatioValue | double | 转换比 |
| isTrack | bool | 是否是地轨 |
| encoderBitLineditValue | double | 编码器位数 |
| inverseLimitValue | double | 反限位 |
| maximumPositiveSpeedValue | double | 最大正转速；单位:倍率 |
| maximumReverseSpeedValue | double | 最大反转速；单位:倍率 |
| motorDir | int | 电机方向；1：正，-1：负 |
| positiveLimitValue | double | 正限位 |
| ratedPositiveSpeedValue | double | 额定正转速；单位:rpm |
| ratedReverseSpeedValue | double | 额定反转速；单位:rpm |
| reductionRatioValue | double | 减速比 |
| maxAccValue | double | 最大加速度；单位:速度的倍率 |
| maxDecValue | double | 最大减速度；单位:速度的倍率 |
| selectBindServo | uint | 选择需要绑定的伺服编号 |

**请求示例：**

```json
{
  "independentAxisParameter": {
    "axisNum": 0,
    "angularDistanceConversionRatioValue": 0.0,
    "isTrack": false,
    "encoderBitLineditValue": 0.0,
    "inverseLimitValue": 0.0,
    "maximumPositiveSpeedValue": 0.0,
    "maximumReverseSpeedValue": 0.0,
    "motorDir": 0,
    "positiveLimitValue": 0.0,
    "ratedPositiveSpeedValue": 0.0,
    "ratedReverseSpeedValue": 0.0,
    "reductionRatioValue": 0.0,
    "maxAccValue": 0.0,
    "maxDecValue": 0.0,
    "selectBindServo": 0
  }
}
```

### 独立控制轴 PV 运动

**命令字：** `0x30E0`

**参数说明：**

| 参数名 | 类型 | 说明 | 取值范围 |
|--------|------|------|----------|
| robot | int | 机器人编号 | [1,4] |
| axisNum | int | 轴编号 | - |
| vel | int | 轴速度；单位:rpm | [-6000,6000] |
| dir | int | 运动方向；1：正，-1：反向 | - |
| acc | double | 加速度 | - |
| dec | double | 减速度 | - |

```json
  "dir": 1,

  "dec": 50.0
}
```

## 独立轴运动说明

### 运动控制模式

独立轴提供以下几种运动控制方式：

| 控制方式 | 命令字 | 说明 |
|----------|--------|------|
| PV 运动 | `0x30E0` | 速度控制模式，以指定速度和方向持续运动 |
| 点动 | `0x30E7` | Jog 模式，按住时持续运动，松开停止 |
| 回零 | `0x30E5` | 回到零点位置 |

### 运动停止方式

| 停止方式 | 命令字 | 说明 |
|----------|--------|------|
| PV 停止 | `0x30E1` | 停止 PV 运动 |
| 取消运动 | `0x30E4` | 取消独立控制运动 |
| 回零停止 | `0x30E6` | 停止回零操作 |

### 操作流程

1. 通过参数命令（`0x2800`–`0x280B`）完成独立轴参数与多圈值配置
2. 使用 `0x30E5` 回零或 `0x30E7` 点动完成位置准备
3. 发送运动命令（PV 或点动）
4. 通过 `0x30E1` / `0x30E4` / `0x30E6` 停止对应运动

## 多圈值

独立轴多圈值用于编码器圈数溢出后的位置还原。

### 设置独立轴多圈值

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x2809` | 上位机 → 控制器 | 设置独立轴多圈值 |
| `0x280A` | 上位机 → 控制器 | 查询独立轴多圈值 |
| `0x280B` | 控制器 → 上位机 | 独立轴多圈值应答 |

> `0x280B`：发送该命令的代码没有通过 `rootSend` 写入数据区字段。

**请求参数（0x2809）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `axisNum` | uint | 轴数量 | >=1 |
| `independentAxisEncodeOverflow.enable` | bool | 使能 | true / false |
| `independentAxisEncodeOverflow.encoderType` | int | 编码器类型 | — |
| `independentAxisEncodeOverflow.encoderRangeMode` | — | 编码器范围模式 | — |
| `independentAxisEncodeOverflow.encoderValueMax` | string | 编码器值最大 | 字符串 |
| `independentAxisEncodeOverflow.encoderValueMin` | string | 编码器值最小 | 字符串 |

```json
{
    "axisNum": 1,
    "independentAxisEncodeOverflow": {
        "enable": true,
        "encoderType": 1,
        "encoderValueMax": "",
        "encoderValueMin": ""
    }
}
```

**请求参数（0x280A）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `axisNum` | — | 轴数量 |
