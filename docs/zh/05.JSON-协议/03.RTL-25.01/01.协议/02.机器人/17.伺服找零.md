# 伺服找零

伺服找零（原点回归）由控制器内部状态机执行：上位机设置寻位零点序号后启动回零，可暂停、查询回零状态与切换模式结果。

---

## 命令列表

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x3760` | 上位机 → 控制器 | 设置伺服寻位零点ORDER |
| `0x3761` | 上位机 → 控制器 | 查询伺服寻位零点ORDER |
| `0x3762` | 控制器 → 上位机 | 伺服寻位零点ORDER应答 |
| `0x3763` | 上位机 → 控制器 | 伺服寻位零点 |
| `0x3764` | 控制器 → 上位机 | 伺服HASHOMED |
| `0x3765` | 上位机 → 控制器 | 伺服ENTER原点模式 |
| `0x3766` | 控制器 → 上位机 | 伺服切换模式结果 |
| `0x3767` | 上位机 → 控制器 | 伺服原点PAUSED |
| `0x3768` | 控制器 → 上位机 | 伺服原点状态应答 |

### 设置伺服寻位零点ORDER

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x3760` | 上位机 → 控制器 | 设置伺服寻位零点ORDER |
| `0x3761` | 上位机 → 控制器 | 查询伺服寻位零点ORDER |
| `0x3762` | 控制器 → 上位机 | 伺服寻位零点ORDER应答 |

**请求参数（0x3760）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `isExternalAxis` | bool | 是否外部轴 | true / false |
| `axisOrderSearchForZero[]` | `array<int>` | — | 数组 |
| `externalAxisOrderSearchForZero[]` | `array<int>` | — | 数组 |

```json
{
    "robot": 1,
    "isExternalAxis": true,
    "axisOrderSearchForZero": [
        1
    ],
    "externalAxisOrderSearchForZero": [
        1
    ]
}
```

**请求参数（0x3761）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `isExternalAxis` | bool | 是否外部轴 | true / false |

```json
{
    "robot": 1,
    "isExternalAxis": true
}
```

**应答参数（0x3762）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `axisOrderSearchForZero` | int | — |
| `externalAxisOrderSearchForZero` | int | — |

```json
{
    "axisOrderSearchForZero": 1,
    "externalAxisOrderSearchForZero": 1
}
```

### 伺服寻位零点

| 命令字 | 方向 | 含义 |

**请求参数（0x3763）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |

