# 自定义按键

## 概述

自定义按键用于将上位机按键或外部硬件按键映射为指定机器人的动作，支持位置变量运动、轴向点动、IO 输出与焊接功能等。每台机器人独立保存一套按键配置，控制器以 `robot - 1` 作为数组下标访问。

上位机通过 `0x1400` 整体下发并保存某台机器人的配置（保存后立即重新加载生效），通过 `0x1401` 查询，控制器通过 `0x1402` 返回查询结果。

---

## 协议一览

| 命令码 | 方向 | 作用 | 是否有应答 |
|---:|---|---|---|
| `0x1400` | 上位机 → 控制器 | 整体保存某机器人的自定义按键配置，并立即重新加载生效 | 无 |
| `0x1401` | 上位机 → 控制器 | 查询某机器人的自定义按键配置 | 是，返回 `0x1402` |
| `0x1402` | 控制器 → 上位机 | 返回自定义按键配置 | 无 |

---

## 设置自定义按键（0x1400）


**方向：** 上位机 → 控制器

**应答：** 无

整体保存某机器人的自定义按键配置，保存后立即重新加载生效。

### 请求格式

```json
{
  "robot": 1,
  "customKey": {
    "key": [],
    "name": [],
    "note": [],
    "port": [],
    "condition": [],
    "conditionTime": [],
    "conditionType": [],
    "function": [],
    "functionName": [],
    "functionIO": [],
    "functionType": [],
    "functionAxis": [],
    "functionDirection": [],
    "enable": []
  }
}
```

### 节点说明

| 节点 | 含义 | 类型 | 取值范围 / 说明 |
|---|---|---|---|
| `robot` | 目标机器人编号 | int | `1 ~ 4`；实际应为 `1 ~ 当前机器人数`。控制器按 `robot - 1` 作为数组下标，未做范围校验 |
| `customKey` | 自定义按键配置对象 | object | SET 会整体覆盖该机器人的配置 |
| `customKey.key[i]` | 按键标识 | string | 按键标识字符串 |
| `customKey.name[i]` | 显示名称 | string | UTF-8 字符串，仅显示，如 `"预制按键J7"` |
| `customKey.note[i]` | 备注 | string | UTF-8 字符串，仅显示，可为空 |
| `customKey.port[i]` | DI 输入端口号 | int | `0` = 未绑定；`1 ~ 当前 DI 端口总数`。仅 IO 按键使用，从 1 开始编号 |
| `customKey.condition[i]` | 触发条件 | int | `0 ~ 3` |
| `customKey.conditionTime[i]` | 长按判定时间 | int | `100 ~ 5000`，单位 ms；仅 `condition = 1` 时有效 |
| `customKey.conditionType[i]` | 触发后动作方式 | int | `0` 或 `1` |
| `customKey.function[i]` | 功能类型 | int | `0 ~ 3` |
| `customKey.functionName[i]` | 位置变量名 | string | 作业中的位置名，如 `"GP0001"`；`function = 0` 时使用 |
| `customKey.functionIO[i]` | DO 端口标签 | string | 格式 `"<组>-<序号>"`，如 `"1-1"`；硬件按键的 IO 输出功能使用 |
| `customKey.functionType[i]` | DO 输出方式 | int | `0` = 输出 0，`1` = 输出 1，`2` = 翻转；硬件按键的 IO 输出功能使用 |
| `customKey.functionAxis[i]` | 轴编号 | int | `1 ~ 7` = J1 ~ J7；`8 ~ 14` = O1 ~ O7；`function = 1` 时使用 |
| `customKey.functionDirection[i]` | 点动方向 | int | `1` = 正向 `+`，`-1` = 反向 `-`；`function = 1` 时使用 |
| `customKey.enable[i]` | 是否使能 | bool | `true` / `false`；`false` 时控制器把该条映射的端口按 0 处理 |

::: tip 并行数组结构
`customKey` 下的各数组按相同下标 `i` 对应同一条按键配置，数组长度 `N` 即按键条数。
:::

## 查询自定义按键（0x1401）


**方向：** 上位机 → 控制器

**应答：** 是，返回 `0x1402`

### 请求格式

| 字段 | 类型 | 说明 |
|---|---|---|
| `robot` | int | 目标机器人编号 |

```json
{
  "robot": 1
}
```

---

## 查询应答（0x1402）


**方向：** 控制器 → 上位机

**应答：** 无

返回节点与 `0x1400` 的请求节点一致，包含 `robot` 与 `customKey` 的全部字段，字段含义同上文节点说明。

---

## 注意事项

::: warning 机器人编号未做范围校验
控制器直接以 `robot - 1` 作为数组下标，未校验 `robot` 是否在有效范围内。`robot` 超出 `1 ~ 当前机器人数` 时可能访问到错误数据，上位机必须自行校验。
:::

::: warning SET 为整体覆盖
`0x1400` 会整体覆盖该机器人的自定义按键配置，未下发的按键不会保留。下发前应完整构造全部按键数据。
:::

### 设置自定义密钥使能

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x1403` | 上位机 → 控制器 | 设置自定义密钥使能 |

**请求参数（0x1403）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `index` | int | 索引 | — |
| `enable` | `array<bool>` | 使能 | 数组 |

```json
{
    "robot": 1,
    "index": 1,
    "enable": [
        true
    ]
}
```
