# 打包点

打包点（PACKING 点）以一组关节或笛卡尔数值的形式保存在控制器中，上位机可写入、回读该点位，并指示机器人移动到该点位。

---

### 设置PACKING点位

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x3666` | 上位机 → 控制器 | 设置PACKING点位 |
| `0x3667` | 上位机 → 控制器 | 查询PACKING点位 |
| `0x3668` | 控制器 → 上位机 | PACKING点位应答 |

> `0x3667`：该命令的处理器未读取 `rootRecv` 中的字段。

**请求参数（0x3666）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `packing_point[]` | array<double> | — |

```json
{
    "packing_point": [
        1.0
    ]
}
```

**应答参数（0x3668）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `packing_point[]` | array<double> | — |

```json
{
    "packing_point": [
        1.0
    ]
}
```

### 移动到PACKING点位

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x3669` | 上位机 → 控制器 | 移动到PACKING点位 |

> `0x3669`：该命令的处理器未读取 `rootRecv` 中的字段。
