### 外部按键

外部按键用于把 DI 输入映射为控制器功能（拖拽、点动、寻位采集/再现、上电/下电、快捷指令等），也可把机器人当前状态映射为 DO 输出（状态提示）。查询与应答的对象都是「当前机器人」（由切换机器人命令决定）。

| 命令码 | 方向 | 含义 |
|---|---|---|
| `0x4020` | HMI → 控制器 | 查询「功能控制」页参数（外部按键 DI 配置 + 焊接拖拽参数） |
| `0x4021` | 控制器 → HMI | `0x4020` 的应答，返回上面两组参数的当前值 |
| `0x4024` | HMI → 控制器 | 设置外部按键参数：功能控制（DI）或状态提示（DO），可同时写入焊接拖拽参数 |

相邻姊妹命令便于对照：`0x4022` / `0x4023`（状态提示 DO 配置查询 / 应答）；`0x4025`（外部快捷键触发的快捷指令上报）；`0x4026`（清除编辑作业名标志、清理焊接状态）。

**通讯方式：** 控制器为服务端，端口 `6000`（net）/ `6001`（net6001），两路挂同一个解析器；应答从收到请求的那条连接原路返回。帧格式为通用 TLV 帧（`0x4E66` + 长度 + 命令码 + JSON + CRC32），详见《[JSON 协议总览](../../../index.md)》的「数据包格式」。

- CRC32 覆盖从偏移 2 起的 `len + 4` 字节（长度 + 命令码 + 载荷），大端
- 接收端支持循环缓冲拆帧，CRC 错误的整帧丢弃并记录日志
- 单帧建议 ≤ 2 KB（`NET_MSG_MAX_SIZE = 2048 + 128`）
- 成功无 ACK；失败通过消息通道推送 `Msg_ComunicationError_`（`0x7008`，内容为「指令[0xxxxx]格式错误/参数错误」），不是命令应答

#### 控制器回复上位机功能控制参数（0x4021）

**命令字：** `0x4021`

| 字段 | 类型 | 含义 |
|---|---|---|
| `hardwareTypeArr` | int[] | 长度 25。每个功能键的硬件类型：`0` = IO，`1` = SERVO（预留，当前固件仅在 `0` = IO 时才建立按键线程） |
| `IoInPortArr` | int[] | 长度 25。功能键对应的 DI 输入端口号，`0` = 该功能未启用 |
| `parameterArr` | int[] | 长度 25。触发电平：`0` = 低电平有效，`1` = 高电平有效（与 `IO_In(port)` 比较） |
| `modeArr` | int[] | 长度 19，实读索引 0~18。按键动作方式：`0` = 长按（3~10 s 松开执行），`1` = 短按（5 ms~3 s 松开执行），`2` = 保持（电平匹配期间触发一次），`3` = 上升沿，`4` = 下降沿 |

| `craft.swingWeldCraft` | int | 摆焊工艺号 |

| `craft.locationTableNumber` | int | 寻位表号 |

| `selectJobname.jobName` | string | 作业名（`mode = 0` 时可为空） |

#### 上位机设置功能控制或状态提示参数（0x4024）

**命令字：** `0x4024`

无成功应答；写文件后调用 `g_extern_key->checkExternKeyIO()` 立即重新加载并重建按键线程（无需重启）。

| 字段 | 类型 | 含义 |
|---|---|---|
| `_isFunctionalControl` | bool | 分支开关：`true` = 保存到「功能控制」；`false` / 缺省 = 保存到「状态提示」 |
| `hardwareTypeArr` | int[] | 同 `0x4021`；状态提示只取前 11 项 |
| `portArr` | int[] | 功能控制时写入 `functionControl.IoInPortArr`（DI 口）；状态提示时写入 `statusPromp.IoOutPortArr`（DO 口） |
| `parameterArr` | int[] | 功能控制：触发电平 `0` / `1`；状态提示：输出状态 `0` = 常灭，`1` = 常亮，`2` = 闪烁（480 ms 亮 / 500 ms 灭） |
| `modeArr` | int[] | 仅功能控制使用（状态提示忽略） |
| `isClearTrack` | int | 仅功能控制使用 |
| `fastCommand` | int[] | 仅功能控制使用，长度 5 |
| `weldDragTeach` | object（可选） | 焊接拖拽参数，逐字段写入当前机器人模型文件，结构同 `0x4021` 的 `craft` / `speed` / `weldMode` / `selectJobname`（不含 `weldBeadSize`） |
| `dragTeachSelectCraft` | int（可选） | 写入模型文件根节点，`0` = 焊接，`1` = 无 |

**落盘目标：**

| 分支 | 写入文件 | 写入节点 |
|---|---|---|
| `_isFunctionalControl = true` | 控制器启动参数文件 | `functionControl.hardwareTypeArr` / `IoInPortArr` / `parameterArr` / `modeArr` / `isClearTrack` / `fastCommand` |
| `_isFunctionalControl = false` | 控制器启动参数文件 | `statusPromp.hardwareTypeArr` / `IoOutPortArr` / `parameterArr`（只写前 11 项对应数组，数组整体覆盖） |
| `weldDragTeach` / `dragTeachSelectCraft` | 当前机器人模型文件 | `weldDragTeach.craft` / `speed` / `weldMode` / `selectJobname`、根节点 `dragTeachSelectCraft` |

::: warning 行为注意
- JSON 解析失败 → `FMT_ERR`，推送 `0x7008` 指令错误提示；解析成功即视为成功（无回包）

- `checkExternKeyIO()` 会重新执行 `readExternKeyIOPara()`，同时刷新外部按键配置和焊接拖拽运行参数（`g_weld_drag_teach.set_weld_drag_parament`）
:::

#### 数组索引与功能对照

`hardwareTypeArr`、`IoInPortArr`、`portArr`、`parameterArr` 均为 25 项；`modeArr` 实读索引 0~18（索引 19~24 的切换类按键固定为「保持」方式）。`0x4020` 应答与 `0x4024` 请求共用该索引。

| 0 | 拖拽模式 | 13 | 快捷指令 3 |
| 1 | 点动模式 | 14 | 快捷指令 4 |
| 2 | 开始寻位采集 | 15 | 快捷指令 5 |
| 3 | 结束寻位采集 | 16 | 删除一条指令 |
| 4 | 开始寻位再现 | 17 | 清空作业 |
| 5 | 结束寻位再现 | 18 | 运行模式启动 |
| 6 | 使能上电 | 19 | 切换到 IO（远程）模式 |
| 7 | 使能下电 | 20 | 切换到运行模式 |
| 8 | 机器手开 | 21 | 切换到示教模式 |
| 9 | 机器手关 | 22 | 切换到 IO 模式（第二组） |
| 10 | 保存轨迹 | 23 | 切换到运行模式（第二组） |
| 11 | 快捷指令 1 | 24 | 切换到示教模式（第二组） |
| 12 | 快捷指令 2 | | |

状态提示（`0x4024` 的 `_isFunctionalControl = false`）只使用索引 0~10，语义是「当前机器人处于对应状态时点亮/闪烁对应 DO 口」（如拖拽/点动、开始/结束寻位、伺服上/下电等）。
