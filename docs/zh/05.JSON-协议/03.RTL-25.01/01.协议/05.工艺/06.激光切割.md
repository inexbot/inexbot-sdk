# 激光切割

激光切割工艺包括激光设备与 IO 端口配置、模拟量匹配、切割参数、点射与手动操作、脉冲输出和功率（速度 POWER）控制。

### 设置激光IO端口

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x8400` | 上位机 → 控制器 | 设置激光IO端口 |

### 设置激光设备

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x8403` | 上位机 → 控制器 | 设置激光设备 |

**请求参数（0x8403）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `equipment.arrivalOutLightMode` | int | 0:到位出光模式、1:直接出光模式 |
| `equipment.preAspiratedTime` | double | 提前送气时间 |
| `equipment.waitLiftUpTime` | double | 等待上抬时间 |
| `equipment.waitFollowTime` | double | 等待跟随时间 |
| `equipment.RetreatDistance` | double | 回退距离 |
| `equipment.delAspiratedMode` | int | 关气模式,1:延后关气,0:提前关气 |
| `equipment.delAspiratedTime` | double | 提前延后关气时间 |
| `perforate.time` | double | 时间 |
| `perforate.pressure` | double | 压力 |
| `perforate.power` | int | 上电 |
| `perforate.freq` | int | 频率 |
| `perforate.dutyRatio` | int | 占空比比例 |

```json
{
    "equipment": {
        "arrivalOutLightMode": 1,
        "preAspiratedTime": 1.0,
        "waitLiftUpTime": 1.0,
        "waitFollowTime": 1.0,
        "RetreatDistance": 1.0,
        "delAspiratedMode": 1,
        "delAspiratedTime": 1.0
    },
    "perforate": {
        "time": 1.0,
        "pressure": 1.0,
        "power": 1,
```

### 设置激光脉冲输出

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x8416` | 上位机 → 控制器 | 设置激光脉冲输出 |
| `0x8417` | 上位机 → 控制器 | 查询激光脉冲输出 |
| `0x8418` | 控制器 → 上位机 | 激光脉冲输出应答 |

> `0x8417`：该命令的处理器未读取 `rootRecv` 中的字段。

**请求参数（0x8416）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `num` | uint | 编号/数量 |
| `type` | int | 类型 |
| `enable` | bool | 使能 |

```json
{
    "num": 1,
    "type": 1,
    "enable": true
}
```

**应答参数（0x8418）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `freqEnable` | bool | 频率使能 |
| `dutyRatioEnable` | bool | 占空比比例使能 |

```json
{
    "freqEnable": true,
    "dutyRatioEnable": true
}
```
