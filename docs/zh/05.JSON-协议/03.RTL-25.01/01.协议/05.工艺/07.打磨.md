# 打磨

打磨工艺参数设置，包括刀具磨损补偿、起止工具偏移与自动进给参数。

---

### 设置打磨参数

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x8500` | 上位机 → 控制器 | 设置打磨参数 |
| `0x8501` | 上位机 → 控制器 | 查询打磨参数 |
| `0x8502` | 控制器 → 上位机 | 打磨参数应答 |

**请求参数（0x8500）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `craftID` | int | 工艺号 | — |
| `polish.toolWear` | double | 刀具补偿 | [-100,100] |
| `polish.startToolOffset.X` | double | X 轴 | [-1000,1000] |
| `polish.startToolOffset.Y` | double | Y 轴 | [-1000,1000] |
| `polish.startToolOffset.Z` | double | Z 轴 | [-1000,1000] |
| `polish.endToolOffset.X` | double | X 轴 | [-1000,1000] |
| `polish.endToolOffset.Y` | double | Y 轴 | [-1000,1000] |
| `polish.endToolOffset.Z` | double | Z 轴 | [-1000,1000] |
| `polish.autoFeed.value` | double | 值 | [-100,100] |
| `polish.autoFeed.cycle` | int | 周期 | — |

```json
{
    "robot": 1,
    "craftID": 1,
    "polish": {
        "toolWear": 1.0,
        "startToolOffset": {
            "X": 1.0,
            "Y": 1.0,
            "Z": 1.0
        },
        "endToolOffset": {
            "X": 1.0,
            "Y": 1.0,
            "Z": 1.0
        },
        "autoFeed": {
            "value": 1.0,
            "cycle": 1
        }
    }
}
```

**请求参数（0x8501）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `craftID` | int | 工艺号 | — |

```json
{
    "robot": 1,
    "craftID": 1
}
```

**应答参数（0x8502）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `craftID` | int | 工艺号 | — |
| `polish.autoFeed.cycle` | int | 周期 | — |
| `polish.autoFeed.value` | double | 值 | [-100,100] |
| `polish.endToolOffset.X` | double | X 轴 | [-1000,1000] |
| `polish.endToolOffset.Y` | double | Y 轴 | [-1000,1000] |
| `polish.endToolOffset.Z` | double | Z 轴 | [-1000,1000] |
| `polish.startToolOffset.X` | double | X 轴 | [-1000,1000] |
| `polish.startToolOffset.Y` | double | Y 轴 | [-1000,1000] |
| `polish.startToolOffset.Z` | double | Z 轴 | [-1000,1000] |
| `polish.toolWear` | double | 刀具补偿 | [-100,100] |

```json
{
    "robot": 1,
    "craftID": 1,
    "polish": {
        "autoFeed": {
            "cycle": 1,
            "value": 1.0
        },
        "endToolOffset": {
            "X": 1.0,
            "Y": 1.0,
            "Z": 1.0
        },
        "startToolOffset": {
            "X": 1.0,
            "Y": 1.0,
            "Z": 1.0
        },
        "toolWear": 1.0
    }
}
```
