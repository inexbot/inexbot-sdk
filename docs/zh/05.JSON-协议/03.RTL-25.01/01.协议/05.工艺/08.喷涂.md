# 喷涂

喷涂工艺包括模拟量组、数字参数、喷涂顺序与轨迹、手动操作、当前模拟量与出油时间设置。

---

### 设置喷涂模拟量组

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x8600` | 上位机 → 控制器 | 设置喷涂模拟量组 |

**请求参数（0x8600）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `ID` | int | 编号 | — |
| `flow` | double | 流量 | — |
| `sector` | double | 扇面 | — |
| `atom` | double | 雾化 | — |
| `Aout.flowAnalogQuantity` | int | 流量模拟量数量 | — |
| `Aout.secterAnalogQuantity` | int | — | — |
| `Aout.atomizationAnalogQuantity` | int | — | — |
| `note` | string | 注释 | 字符串 |

```json
{
    "robot": 1,
    "ID": 1,
    "flow": 1.0,
    "sector": 1.0,
    "atom": 1.0,
    "Aout": {
        "flowAnalogQuantity": 1,
        "secterAnalogQuantity": 1,
        "atomizationAnalogQuantity": 1
    },
    "note": ""
}
```
