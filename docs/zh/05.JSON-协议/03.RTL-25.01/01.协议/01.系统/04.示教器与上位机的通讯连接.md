# 示教器与上位机的通讯连接

## 心跳

> **说明：** 不管什么通讯模式，都应设计心跳模式，确保通讯状态正常。上位机定期发送心跳检查包给控制器，并等待控制器回应。客户端收到心跳包后需要回复心跳回应包，包数据为检查包所携带的时间戳。上位机收到回应包后检查数据是否正确。数据不正确或超时为收到回应，则认为连接可能中断。

### 收到心跳

| 属性 | 类型 | 说明 |
|------|------|------|
| time | int | 时间戳 |

**命令字**：`0x1200`

```json
{
  "time": 123
}
```

### 回应心跳

| 属性 | 类型 | 说明 |
|------|------|------|
| time | int | 时间戳 |

**命令字**：`0x1201`

```json
{
  "time": 123
}
```

## 上位机关机

> **说明：** 上位机断开发送

**命令字**：`0x1210`

| 属性 | 类型 | 说明 |
|------|------|------|
| date | - | 无 |

## 上位机开机

> **说明：** 上位机接入恢复通信

**命令字**：`0x1211`

| 属性 | 类型 | 说明 |
|------|------|------|
| date | - | 无 |

### 发送获取心跳

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x1202` | 上位机 → 控制器 | 发送获取心跳 |

**请求参数（0x1202）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `time` | — | 时间 |

### 获取HEARTBEAT应答

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x1203` | 控制器 → 上位机 | 获取HEARTBEAT应答 |

> `0x1203`：发送该命令的代码没有通过 `rootSend` 写入数据区字段。

### 串口数据发送

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x1220` | 上位机 → 控制器 | 串口数据发送 |

**请求参数（0x1220）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `port` | int | 端口号 |
| `baud` | int | 波特率 |
| `len` | int | 长度 |
| `data[]` | `array<int>` | 数据 |

```json
{
    "port": 1,
    "baud": 1,
    "len": 1,
    "data": [
        1
    ]
}
```

### 查询串口数据

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x1221` | 控制器 → 上位机 | 查询串口数据 |

**应答参数（0x1221）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `data[]` | `array<int>` | 数据 |
| `lenRecv` | int | 长度接收 |

```json
{
    "data": [
        1
    ],
    "lenRecv": 1
}
```

## 判断连接程序是否为旧版控制器通讯

上位机可通过该命令确认控制器通讯版本，以决定是否走旧版命令集。

### 查询COMMUNCATION版本

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x4305` | 上位机 → 控制器 | 查询COMMUNCATION版本 |
| `0x4306` | 控制器 → 上位机 | COMMUNCATION版本应答 |

**请求参数（0x4305）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `version` | string | 版本 |

```json
{
    "version": ""
}
```

**应答参数（0x4306）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `versionMatch` | bool | — |
| `finishinit` | bool | 初始化完成 |

```json
{
    "versionMatch": true,
    "finishinit": true
}
```
