# PROFINET

控制器作为 PROFINET 设备接入时的状态查询与应答。

---

### 获取PROFINET状态

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7370` | 上位机 → 控制器 | 获取PROFINET状态 |

> `0x7370`：该命令的处理器未读取 `rootRecv` 中的字段。

### PROFINET状态应答

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7371` | 控制器 → 上位机 | PROFINET状态应答 |
| `0x7372` | 上位机 → 控制器 | 设置PROFINET状态 |

**应答参数（0x7371）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `profinet_restart_required` | — | — |
| `profinet_running_state` | — | — |
| `profinet_byte_count` | — | — |
| `profinet_connecting_state` | — | — |
| `profinet_plugin` | int | — |

```json
{
    "profinet_plugin": 1
}
```

**请求参数（0x7372）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `profinet_running_switch` | bool | — |
| `profinet_byte_count` | int | — |

```json
{
    "profinet_running_switch": true,
    "profinet_byte_count": 1
}
```
