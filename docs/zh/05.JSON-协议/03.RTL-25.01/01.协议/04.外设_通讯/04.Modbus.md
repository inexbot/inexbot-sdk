# Modbus

Modbus 主站/从站的参数配置、使能与心跳检查，以及主站连接状态、读取与写入查询。控制器通过 6000 / 6001 端口接收这些命令，具体参数见下方各命令。

---

### 设置Modbus主站

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7300` | 上位机 → 控制器 | 设置Modbus主站 |
| `0x7301` | 上位机 → 控制器 | 查询Modbus主站 |
| `0x7302` | 控制器 → 上位机 | Modbus主站应答 |

**请求参数（0x7300）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `masterStation.processNumber` | int | 主站编号/进程号 |

```json
{
    "masterStation": {
        "processNumber": 1
    }
}
```

**请求参数（0x7301）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `processNumber` | int | 主站编号/进程号 |

```json
{
    "processNumber": 1
}
```

**应答参数（0x7302）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `modbus_state` | bool | Modbus 状态 |
| `startAddress` | bool | 起始地址 |
| `type` | — | 类型 |
| `TCP.IP` | string | — |
| `TCP.port` | int | TCP 端口 |
| `TCP.endian_type` | int | TCP 字节序 |
| `RTU.slaveId` | int | RTU 从站号 |
| `RTU.port` | int | RTU 串口编号 |
| `RTU.baudrate` | int | RTU 波特率 |
| `RTU.checkBit` | string | RTU 校验位 |
| `RTU.dataBit` | int | RTU 数据位 |
| `RTU.stopBit` | int | RTU 停止位 |
| `response_time_out` | int | 读写响应超时 ms |

```json
{
    "modbus_state": true,
    "startAddress": true,
    "TCP": {
        "IP": "",
        "port": 1,
        "endian_type": 1
    },
    "RTU": {
        "slaveId": 1,
        "port": 1,
        "baudrate": 1,
        "checkBit": "",
        "dataBit": 1,
        "stopBit": 1
    },
    "response_time_out": 1
}
```

**请求参数（0x730C）**

| 字段 | 类型 | 说明 | 取值范围 |

| `jobname` | array<string> | 作业名 | 数组 |

```json
{
    "robot": 1,
    "programid": 1,
    "jobname": [
        ""
    ]
}
```

**请求参数（0x730D）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `startprogramid` | int | 起始程序编号 | — |
| `num` | int | 编号/数量 | — |

```json
{
    "robot": 1,
    "startprogramid": 1,
    "num": 1
}
```

**应答参数（0x730E）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `jobnamelist[]` | array<string> | 作业名列表 | 数组 |
| `robot` | int | 机器人号 | — |
| `startprogramid` | int | 起始程序编号 | >=1 |
| `sum` | int | 总数 | — |

```json

        ""
    ],
    "robot": 1,
    "startprogramid": 1,
    "sum": 1

```
