# 其他外设

## 编码器

### 说明

上位机设置外部轴编码器溢值参数

**命令字：** `0x7200`

#### 参数列表

| 字段名 | 类型 | 范围 | 说明 |
|--------|------|------|------|
| externalAxis | array | - | 外部轴编码器最大值最小值参数列表，长度为当前外部轴轴数 |
| encode | array | - | 编码器最大值最小值参数列表，长度为该轴从动轴数目+1 |
| max | double | [-2^32, 2^32] | 编码器最大值 |
| min | double | [-2^32, 2^32] | 编码器最小值 |
| externalGroupNum | int | [1, 3] | 要设置参数的轴组号 |
| robot | int | [1, 4] | 当前机器人号 |

#### 请求示例

```json
{
  "externalAxis": [
    {
      "encode": [
        {
          "max": "100.0",
          "min": "-100.0"
        }
      ]
    }
  ],
  "externalGroupNum": 1,
  "robot": 2
}
```

### 说明

控制器回复上位机外部轴编码器溢值参数

**命令字：** `0x7202`

#### 参数列表

| 字段名 | 类型 | 范围 | 说明 |
|--------|------|------|------|
| externalAxis | array | - | 外部轴编码器最大值最小值参数列表，长度为当前外部轴轴数 |
| enable | int | [0, 1] | 编码器多圈值溢出计数功能；0表示未开启，1表示已开启 |
| encode | array | - | 编码器最大值最小值参数列表，长度为该轴从动轴数目+1 |
| max | double | [-2^32, 2^32] | 编码器最大值 |
| min | double | [-2^32, 2^32] | 编码器最小值 |
| externalGroupNum | int | [1, 3] | 轴组号 |
| robot | int | [1, 4] | 当前机器人号 |

#### 响应示例

```json
{
  "externalAxis": [
    {
      "enable": 0,
      "encode": [
        {
          "max": "100.0",
          "min": "-100.0"
        }
      ]
    }
  ],
  "externalGroupNum": 1,
  "robot": 2
}
```

## 伺服内部参数

### 说明

控制器发送伺服内部参数时会十个参数为一组，分多次发送给上位机

### 上位机设置伺服参数

**命令字：** `0x7240`

#### 参数列表

| 字段名 | 类型 | 范围 | 说明 |
|--------|------|------|------|
| robot | int | [1, 4] | 当前机器人号 |
| servoNum | int | - | 需要设置的轴号 |
| servo | object | - | 伺服内部参数列表；不同机型获取到参数不一致 |
| value | int/double | - | 设置的参数值 |

### 设置同步编码器溢出使能参数

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7203` | 上位机 → 控制器 | 设置同步编码器溢出使能参数 |

**请求参数（0x7203）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `robot` | int | 机器人号 | [1,4] |
| `externalGroupNum` | int | 外部轴组号 | — |
| `externalAxis[].enable` | int | 使能 | — |
| `externalAxis[].encode[].max` | double | 最大 | — |
| `externalAxis[].encode[].min` | double | 最小 | — |
| `externalAxis[].encode[].encoderType` | int | 编码器类型 | — |
| `externalAxis[].encode[].encoderRange` | — | 编码器范围，max-min+1 | — |

```json
{
    "robot": 1,
    "externalGroupNum": 1,
    "externalAxis": [
        {
            "enable": 1,
            "encode": [
                {
                    "max": 1.0,
                    "min": 1.0,
                    "encoderType": 1,
                    "encoderRange": {}
                }
            ]
        }
    ]
}
```

## 伺服数据采集

按采集项配置伺服数据采集，并通过 SERVODATA 列表回读结果。

### 设置伺服数据COLLECT

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7243` | 上位机 → 控制器 | 设置伺服数据COLLECT |

**请求参数（0x7243）**

| 字段 | 类型 | 说明 | 取值范围 |
|---|---|---|---|
| `axis.idx` | int | 索引 | <=5 |
| `axis.state` | bool | 状态 | true / false |
| `data.targetPositionValue` | bool | 目标位置值 | true / false |
| `data.actualPositionValue` | bool | 实际位置值 | true / false |
| `data.motorSpeed` | bool | 电机速度 | true / false |
| `data.motorLoad` | bool | 电机负载 | true / false |
| `data.motorCurrent` | bool | 电机当前 | true / false |
| `data.motorTorque` | bool | 电机力矩 | true / false |
| `data.motorTemperature` | bool | 电机温度 | true / false |

```json
{
    "axis": {
        "idx": 1,
        "state": true
    },
    "data": {
        "targetPositionValue": true,
        "actualPositionValue": true,
        "motorSpeed": true,
        "motorLoad": true,
        "motorCurrent": true,
        "motorTorque": true,
        "motorTemperature": true
    }
}
```

### 获取伺服数据COLLECT

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7244` | 上位机 → 控制器 | 获取伺服数据COLLECT |

> `0x7244`：该命令的处理器未读取 `rootRecv` 中的字段。

### 接收伺服数据COLLECT

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7245` | 控制器 → 上位机 | 接收伺服数据COLLECT |

> `0x7245`：发送该命令的代码没有通过 `rootSend` 写入数据区字段。

### 启动OR结束伺服数据COLLECT

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7246` | 上位机 → 控制器 | 启动OR结束伺服数据COLLECT |

**请求参数（0x7246）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `enabled` | bool | 使能 |

```json
{
    "enabled": true
}
```

### 接收SERVODATA列表
