# OPC UA

OPC UA 参数设置与查询。控制器侧的 OPC UA 服务参数通过下列命令写入，节点读写与订阅由 OPC UA 客户端直接访问服务端完成。

---

### 设置OPC UA参数

| 命令字 | 方向 | 含义 |
|--------|------|------|
| `0x7350` | 上位机 → 控制器 | 设置OPC UA参数 |
| `0x7351` | 上位机 → 控制器 | 查询OPC UA参数 |
| `0x7352` | 控制器 → 上位机 | OPC UA参数应答 |

> `0x7351`：该命令的处理器未读取 `rootRecv` 中的字段。

**请求参数（0x7350）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `server.enable` | bool | 使能 |
| `server.ip` | string | — |
| `server.port` | int | 端口号 |
| `client.enable` | bool | 使能 |
| `client.ip` | string | — |
| `client.port` | int | 端口号 |
| `client.resource` | string | 资源 |

```json
{
    "server": {
        "enable": true,
        "ip": "",
        "port": 1
    },
    "client": {
        "enable": true,
        "ip": "",
        "port": 1,
        "resource": ""
    }
}
```

**应答参数（0x7352）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `client.enable` | — | 使能 |
| `client.ip` | string | — |
| `client.port` | int | 端口号 |
| `client.resource` | string | 资源 |
| `server.ip` | string | — |
| `server.port` | int | 端口号 |
| `server.enable` | — | 使能 |

```json
{
    "client": {
        "ip": "",
        "port": 1,
        "resource": ""
    },
    "server": {
        "ip": "",
        "port": 1
    }
}
```
