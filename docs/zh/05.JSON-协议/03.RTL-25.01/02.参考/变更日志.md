# 变更日志

## RTL-25.01（相对 RTL-24.03 文档）

依据：控制器源码 RTL 25.01.03（代码基线 `Inexbot_Controller` `4bd387087`），逐条核对 6000 / 6001 端口命令字与 7000 端口上位机服务命令。

### 新增页面

- 机器人：[打包点](../01.协议/02.机器人/16.打包点.md)（`0x3666`–`0x3669`）、[伺服找零](../01.协议/02.机器人/17.伺服找零.md)（`0x3760`–`0x3768`）
- 外设/通讯：[PROFINET](../01.协议/04.外设_通讯/11.PROFINET.md)（`0x7370`–`0x7372`）
- 工艺：[激光切割](../01.协议/05.工艺/06.激光切割.md)（`0x8400`–`0x841B`）、[打磨](../01.协议/05.工艺/07.打磨.md)（`0x8500`–`0x8502`）、[喷涂](../01.协议/05.工艺/08.喷涂.md)（`0x8600`–`0x8614`）
- 参考：[命令字索引](./02.命令字索引.md)，收录 6000 / 6001 端口全部 1299 条在用命令字（含方向、含义），另附「定义未使用」「重复定义」「枚举」三个附录

### 删除内容

- 冲压工艺（原 `0x8800`–`0x8853`，84 条）已在控制器中删除，文档不再收录
- 电批参数（原 `0x8900`–`0x8906`，7 条）已在控制器中删除，文档不再收录
- 系统章节移除失效的「安全参数」链接（该页内容已并入[干涉区](../01.协议/02.机器人/09.干涉区.md)与[跟随误差与电机过载保护](../01.协议/02.机器人/10.跟随误差&电机过载保护.md)）

### 补充与修正

- 系统、机器人、程序、外设、工艺各页补齐源码中新增或此前遗漏的命令字
- 7000 端口协议补充伺服在线控制与队列模式（`0x1E14`–`0x1E1C`），修正命令字总览与编址规则附录
- 系统章节补充「上位机版本低时使用」「判断连接程序是否为旧版控制器通讯」两节
- 各页末尾新增「源码中定义但未使用的命令」提示，列出该页涉及的仅定义未收发命令字
