# 命令字索引

> 适用版本：RTL 25.01.03（`RTL_VERSION`，见 `h/config/versionNumber.h`）
> 依据：控制器源码 `src/hmi_comm/vxSvr_v2.h` / `cmdParsing.cpp`、`src/method/cmd_data/cmddata.cpp`（代码基线 `Inexbot_Controller` `4bd387087`）

本页收录 **6000 / 6001** 端口全部 **1299** 条命令字：上位机 → 控制器 812 条、控制器 → 上位机 450 条、双向 4 条；另列代码中定义但未使用的命令（附录 B）与重复定义（附录 C）。

- 帧格式与 CRC 校验见[协议总览](../../index.md)；7000 端口是另一套命令字（`0x1E00`–`0x1E1C`），见 [7000 端口协议](../01.协议/01.系统/06.7000端口协议.md)。
- 本页只保证「命令字 ↔ 方向 ↔ 含义」的对应关系；字段结构、取值与 JSON 示例见各章节页面。
- RTL-25.01 已删除冲压（`0x8800`–`0x8853`）与电批（`0x8900`–`0x8906`）章节，本页不再收录。
