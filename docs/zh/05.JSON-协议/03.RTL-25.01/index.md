# RTL-25.01 通讯协议

RTL-25.01 是纳博特控制器的新版本协议。本版文档依据控制器源码逐条核对整理（适用 **RTL 25.01.03**，`RTL_VERSION` 见 `h/config/versionNumber.h`；代码基线 `Inexbot_Controller` `4bd387087`），覆盖 6000 / 6001 端口的全部 **1390** 条命令字与 7000 端口的上位机服务命令。

- 全部命令字见[命令字索引](./02.参考/02.命令字索引.md)，其中 33 条为源码定义但未使用，已单列。
- 帧格式、CRC 校验与端口职责见[协议总览](../index.md)。

> RTL-24.03 进行 bug 修复和关键功能合入；RTL-25.01 在此基础上扩展了差速轮与导航、打包点、伺服找零、交叉激光 TCP 标定、PROFINET 等能力。两个版本的帧格式与端口体系一致，命令字以本版文档为准。

---

## 适用范围

- 所有支持 RTL-25.01 的控制器型号
- 适用场景：新项目开发、需要 25.01 新增能力的集成

## 与 RTL-24.03 文档的主要差异

| 特性     | RTL-24.03     | RTL-25.01                                            |
| -------- | ------------- | ---------------------------------------------------- |
| 通信格式 | TLV 帧（Value 段 JSON） | 同左                                       |
| 命令字   | 按功能分章     | 全量核对 1390 条，附方向、「定义未使用」清单        |
| 机器人   | 参数、运动、状态、标定 | 同左 + 打包点、伺服找零、交叉激光 TCP 标定、差速轮与导航 |
| 工艺     | 码垛、焊接、传送带、寻位、视觉 | 同左 + 激光切割、打磨、喷涂              |
| 外设     | 总线、IO、Modbus、TCP、OPC UA、EIP、软 PLC | 同左 + PROFINET                 |
| 7000 端口 | 查询、运动控制、变量 IO | 同左 + 伺服在线控制与队列模式（`0x1E14`–`0x1E1C`） |

## 命令字速查

| 分类           | 命令字范围              | 说明                                                       |
| -------------- | ----------------------- | ---------------------------------------------------------- |
| 控制器         | `0x1000` – `0x1F0E`     | 初始化、版本、日志、升级、授权、语言、时钟、上位机通讯、操作参数、自定义 |
| 机器人参数     | `0x2000` – `0x20D8`     | 机器人类型、DH、关节/笛卡尔参数、点动、伺服、外部轴          |
| 独立控制轴     | `0x2800` – `0x280B`     | 独立轴参数与状态                                           |
| 差速轮与导航   | `0x2900` – `0x2917`     | 差速轮底盘控制、导航请求与应答                              |
| 运动控制       | `0x3000` – `0x30E7`     | 模式、伺服使能、点动、回零、坐标系切换、上电清错、急停       |
| 状态           | `0x3200` – `0x3277`     | 机器人状态、坐标、报警、碰撞检测                             |
| 工具手/坐标系  | `0x3500` – `0x3593`     | 工具手、用户坐标系、大地坐标系                               |
| 零点/复位/打包 | `0x3600` – `0x3669`     | 零点设置、复位点、打包点                                     |
| 标定           | `0x366A` – `0x3769`     | 4 点/20 点标定、交叉激光 TCP 标定、伺服找零                  |
| 干涉区/保护    | `0x3800` – `0x3882`     | 干涉区、跟随误差、电机过载保护                               |
| 动力学         | `0x4000` – `0x40C2`     | 动力学参数、负载、拖动示教、自适应加减速                     |
| 版本兼容       | `0x4305` – `0x4306`     | 判断上位机程序是否为旧版控制器通讯                           |
| 遥操作         | `0x4600` – `0x463D`     | 三维鼠标、遥操作模式、主从跟随                               |
| 程序           | `0x5000` – `0x5650`     | 程序增删改查、指令编辑、运行控制、程序状态、远程程序          |
| 变量           | `0x6000` – `0x602D`     | 位置变量读取与设置                                          |
| 外设/通讯      | `0x7010` – `0x743F`     | 总线、IO、其它外设、Modbus、TCP、数据上传、FINS、OPC UA、EIP、PROFINET、软 PLC |
| 工艺           | `0x8000` – `0x8614`     | 码垛、视觉、传送带、焊接、激光切割、打磨、喷涂、寻位 |
