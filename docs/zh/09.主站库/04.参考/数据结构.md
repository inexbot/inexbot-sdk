# 数据结构

## 基础类型

| 类型 | C 类型 |
|------|--------|
| `EC_T_BYTE` | `unsigned char` |
| `EC_T_WORD` | `unsigned short` |
| `EC_T_DWORD` | `unsigned int` |
| `EC_T_SBYTE` | `signed char` |
| `EC_T_SWORD` | `signed short` |
| `EC_T_SDWORD` | `signed int` |
| `EC_T_REAL` | `double` |

## PDOAddrData

```c
typedef struct {
    EC_T_WORD index;       // PDO 索引
    EC_T_WORD subIndex;    // PDO 子索引
    EC_T_BYTE* addrMap;    // PDO 对象地址指针
} PDOAddrData;
```
