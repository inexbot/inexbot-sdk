# 主站管理

## API 列表

| 函数 | 说明 |
|------|------|
| `startEcMaster` | 启动 EtherCAT 主站 |
| `enableRealtimeEnvironment` | 启用实时环境 |
| `ECM_LogMsg` | 记录日志消息 |
| `ECM_LogError` | 记录错误日志 |
| `setEcatLicenseKey` | 设置主站密钥（空函数） |
| `isEcatLicenseCorrect` | 获取主站密钥是否有效 |
| `setLogDirName` | 设置日志输出目录 |
| `setEcatLogSwitch` | 设置日志开关 |
| `getCycleTime` | 获取主站实时周期 |
| `getEcLibVersion` | 获取主站库版本 |
| `getEniFileName` | 获取 ENI 文件名 |

### startEcMaster

- **原型：** `int startEcMaster(int argc, char* argv[])`
- **参数：** 第一个参数为周期时间（ms）
- **返回：** 0 成功，非 0 失败

### enableRealtimeEnvironment

- **原型：** `int enableRealtimeEnvironment()`
- **说明：** 启用实时环境（Xenomai / PREEMPT_RT），需在 startEcMaster 前调用

### ECM_LogMsg / ECM_LogError

- **原型：** `void ECM_LogMsg(const char* msg)` / `void ECM_LogError(const char* msg)`
- **说明：** 日志和错误消息输出

### getCycleTime

- **原型：** `CycleTime getCycleTime()`
- **说明：** 获取主站的实时周期时间

### getEcLibVersion

- **原型：** `const char* getEcLibVersion()`
- **返回：** 库版本号字符串
