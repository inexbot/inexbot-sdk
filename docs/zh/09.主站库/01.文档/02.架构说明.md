# 架构说明

纳博特 EtherCAT 主站控制器主站抖动时间小于 20us。`libNexIghEcm` 库可自动生成 ENI 文件，用户只需获取 PDO 操作地址、注册周期任务即可，极大降低使用难度。

## 功能简介

- 自动生成 ENI 配置文件
- PDO 地址自动映射
- SDO 读写接口
- 周期任务注册（每周期回调）
- 从站 ID 匹配回调

## 核心概念

- **PDO（Process Data Object）：** 实时过程数据，每个周期自动交换
- **SDO（Service Data Object）：** 非实时配置数据，按需读写
- **从站编号：** 从 0 开始的 EtherCAT 从站序号
- **ENI 文件：** EtherCAT 网络信息文件（ENI），描述网络拓扑和配置
