# 文件与日志

HAL 层的日志功能通过设备管理器回调实现。

## PWM 设备

### PwmDevice 类

- **set_duty(channel, duty)：** 设置占空比
- **set_frequency(channel, frequency)：** 设置频率
- **enable(channel) / disable(channel)：** 使能/禁用

## 编码器设备

### EncoderDevice 类

- **get_position(channel)：** 读取编码器位置
- **reset(channel)：** 复位编码器

## UPS 设备

### UpsDevice 类

- **get_status()：** 获取 UPS 状态
- **get_battery_level()：** 获取电池电量
