# 系统初始化

## DeviceManager 类

设备管理器单例，管理所有硬件设备的生命周期。

### instance

- **原型：** `static DeviceManager& instance()`
- **返回：** 单例引用

### add_device

- **原型：** `int add_device(std::shared_ptr<Device> device)`
- **返回：** 0 成功

### remove_device

- **原型：** `int remove_device(DeviceType device_type, const std::string& device_name)`

### is_device_exist

- **原型：** `bool is_device_exist(DeviceType device_type, const std::string& device_name) const`

### get_device

- **原型：** `std::shared_ptr<Device> get_device(DeviceType device_type, const std::string& device_name) const`

### get_all_device_name_list / get_device_name_list / get_device_list

按类型查询设备名称或实例列表。
