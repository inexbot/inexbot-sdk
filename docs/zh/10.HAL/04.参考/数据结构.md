# 数据结构

## DeviceType 枚举

```cpp
enum class DeviceType {
    NULL_,              // 空设备
    ANALOG_IO_,         // 模拟输入输出
    CAN_DEVICE_,        // CAN 总线
    DIGITAL_IO_,        // 数字输入输出
    ENCODER_DEVICE_,    // 编码器
    PWM_DEVICE_,        // 脉宽调制
    SERIAL_DEVICE_,     // 串口
    UPS_DEVICE_,        // 不间断电源
    CUSTOM_             // 自定义
};
```
