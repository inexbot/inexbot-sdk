# 五、双臂机器人（Python）

> 本页对应 [C++ 版](../../01.C++/02.接口/05.双臂机器人.md)。**函数名与参数顺序与 C++ 完全一致**（Python SDK 由 C++ 经 SWIG 生成），差异只在两处：
>
> 1. **返回值形态**：C++ 用引用参数回填数据；Python 的返回形态由 SWIG 绑定决定，**逐接口实测**，不按类型推断。
> 2. **少数接口在 Python 中不可直接调用**（绑定缺陷），页面内已逐个标注。

::: warning 本页接口当前 Python SDK 未提供

本页 13 个接口在 `nrc_interface`（Linux / Windows 包均已核对）中**均无同名定义**，Python 侧调用会抛 `AttributeError`。本篇保留 C++ 语义说明用于对接参考，**实现请使用 C++ SDK**；如需 Python 支持请联系纳博特评估排期。

:::

## 功能概述

### set_one_movecomd_completion_callback

设置一条 move 指令执行完成时的回调函数。

**参数说明**（与 C++ 一致）：

| 参数 | 类型 | 说明 |
|------|------|------|
| socketFd | SOCKETFD | 连接句柄 |
| function | void(*)() | 回调函数指针，一条 move 指令执行完成时被调用 |

**C++ 侧返回值描述**：`SUCCESS(0)` 表示成功，负数表示失败。

---

### set_dualarm_user_coord_number / set_dualarm_user_coord_number_robot

设置双臂用户坐标编号。

**参数说明**（与 C++ 一致）：

| 参数 | 类型 | 说明 |
|------|------|------|
| socketFd | SOCKETFD | 连接句柄 |
| robotNum | int | 机器人编号 (1-4)，仅 `_robot` 版本 |
| userNum | int | 用户坐标编号 |

**C++ 侧返回值描述**：`SUCCESS(0)` 表示成功，负数表示失败。

---

### get_dualarm_user_coord_number / get_dualarm_user_coord_number_robot

获取当前使用的用户坐标编号。

**参数说明**（与 C++ 一致）：

| 参数 | 类型 | 说明 |
|------|------|------|
| socketFd | SOCKETFD | 连接句柄 |
| robotNum | int | 机器人编号 (1-4)，仅 `_robot` 版本 |
| userNum | int& | 输出参数，当前用户坐标编号 |

**C++ 侧返回值描述**：`SUCCESS(0)` 表示成功，负数表示失败。

---

### get_dualarm_user_coord_para / get_dualarm_user_coord_para_robot

获取用户坐标参数（含坐标系类型和机械臂号）。

**参数说明**（与 C++ 一致）：

| 参数 | 类型 | 说明 |
|------|------|------|
| socketFd | SOCKETFD | 连接句柄 |
| robotNum | int | 机器人编号 (1-4)，仅 `_robot` 版本 |
| userNum | int | 用户坐标编号 |
| pos | std::vector\<double\>& | 输出参数，用户坐标参数 |
| locationType | int& | 输出参数，坐标系类型：0=静态用户坐标系，1=联动坐标系 |
| mechID | int& | 输出参数，机器人号 |

**C++ 侧返回值描述**：`SUCCESS(0)` 表示成功，负数表示失败。

---

### set_dualarm_user_coordinate_data / set_dualarm_user_coordinate_data_robot

标定双臂用户坐标（写入坐标数据）。

**参数说明**（与 C++ 一致）：

| 参数 | 类型 | 说明 |
|------|------|------|
| socketFd | SOCKETFD | 连接句柄 |
| robotNum | int | 机器人编号 (1-4)，仅 `_robot` 版本 |
| userNum | int | 用户坐标编号 |
| pos | std::vector\<double\> | 坐标数据 |
| locationType | int | 坐标系类型：0=静态用户坐标系，1=联动坐标系 |
| mechID | int | 机器人号 |

**C++ 侧返回值描述**：`SUCCESS(0)` 表示成功，负数表示失败。

---

### dualarm_calibration_oxy / dualarm_calibration_oxy_robot

双臂 OXY 标定。

**参数说明**（与 C++ 一致）：

| 参数 | 类型 | 说明 |
|------|------|------|
| socketFd | SOCKETFD | 连接句柄 |
| robotNum | int | 机器人编号 (1-4)，仅 `_robot` 版本 |
| userNum | int | 用户坐标编号 |
| xyo | std::string | 标定类型：'X'、'Y'、'O'（分别标定 X 轴方向点、Y 轴方向点、原点） |

**C++ 侧返回值描述**：`SUCCESS(0)` 表示成功，负数表示失败。

---

| robotNum | int | 机器人编号 (1-4)，仅 `_robot` 版本 |
