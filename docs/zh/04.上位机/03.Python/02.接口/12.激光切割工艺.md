# 十二、激光切割工艺（Python）

> 本页对应 [C++ 版](../../01.C++/02.接口/12.激光切割工艺.md)。**函数名与参数顺序与 C++ 完全一致**（Python SDK 由 C++ 经 SWIG 生成），差异只在两处：
>
> 1. **返回值形态**：C++ 用引用参数回填数据；Python 的返回形态由 SWIG 绑定决定，**逐接口实测**，不按类型推断。
> 2. **少数接口在 Python 中不可直接调用**（绑定缺陷），页面内已逐个标注。
