# 八、队列运动模式（Python）

> 本页对应 [C++ 版](../../01.C++/02.接口/08.队列运动模式.md)。**函数名与参数顺序与 C++ 完全一致**（Python SDK 由 C++ 经 SWIG 生成），差异只在两处：
>
> 1. **返回值形态**：C++ 用引用参数回填数据；Python 的返回形态由 SWIG 绑定决定，**逐接口实测**，不按类型推断。
> 2. **少数接口在 Python 中不可直接调用**（绑定缺陷），页面内已逐个标注。

本页共 20 个接口，其中 **20 个在 Python SDK 中存在**。

## 8.2 队列运动指令插入

### MoveCmd

`push_back_move*` 系列都收一个 `MoveCmd`（`nrc_define.h`），字段如下：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `targetPosType` | `PosType` | `data(0)` | 点位类型：`data`＝自定义数组，`P/AP/GP/GE`＝系统点位 |
| `targetPosValue` | `vector<double>` | 长度 14 | 目标位置。**前 7 位本体关节，后 7 位外部轴**；`data` 类型必须填 |
| `targetPosName` | `string` | 空 | 用系统点位时填名称，如 `"GP0001"`（仅作业文件模式有效） |
| `coord` | `int` | 0 | 坐标类型：0 关节 / 1 直角 / 2 工具 / 3 用户 |
| `velocity` | `double` | 50 | 速度 |
| `velocitySync` | `double` | 0 | 外部轴速度同步值 |
| `acc` / `dec` | `double` | 50 | 加速度 / 减速度 |
| `pl` | `int` | 0 | 平滑等级 |
| `time` | `int` | 0 | 提前执行时间 |
| `toolNum` | `int` | 0 | 该点位使用的**工具手编号**；运行时机器人当前工具手与此不一致 → 报错 |
| `userNum` | `int` | 0 | 该点位使用的**用户坐标编号**；运行时机器人当前用户坐标与此不一致 → 报错 |
| `configuration` | `int` | 0 | 形态（关节解的分支） |
| `posidtype` | `int` | 0 | 0＝一级变量（`GP0001`），1＝二级变量（`GP[I001]`） |
| `spin` | `int` | 0 | 仅 MOVCA 用：0 姿态不变 / 1 六轴不转 / 2 六轴旋转 |
| `parasync` | `bool` | false | 外部轴是否同步 |

::: warning 工具手 / 用户坐标必须与机器人当前值一致，否则运行时报错
`MoveCmd.toolNum` / `userNum` 是**该点位所属的工具手编号和用户坐标编号**，不是「用不用工具」的开关。运行到这个点时，控制器会比对机器人当前的工具手 / 用户坐标：
- **一致**：正常执行，按该工具/用户坐标换算；
- **不一致**：**直接报错**，不会自动切换过去。

因此队列里的点位要用哪把工具、哪个用户坐标，就把对应编号显式填进去；不要在示教器上临时切了工具/用户坐标再跑同一条队列。切换后要么同步修改队列里的编号，要么重新下发。
:::

---

**Python 中定义**：`nrc_interface.MoveCmd`（构造：`nrc.MoveCmd()`）。

**可用字段**（共 16 个，实测 `dir()`）：

`acc`、`configuration`、`coord`、`dec`、`parasync`、`pl`、`posidtype`、`spin`、`targetPosName`、`targetPosType`、`targetPosValue`、`time`、`toolNum`、`userNum`、`velocity`、`velocitySync`
