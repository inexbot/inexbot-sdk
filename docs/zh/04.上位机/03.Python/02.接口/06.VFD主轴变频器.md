# 六、VFD 主轴变频器控制（Python）

> 本页对应 [C++ 版](../../01.C++/02.接口/06.VFD主轴变频器.md)。**函数名与参数顺序与 C++ 完全一致**（Python SDK 由 C++ 经 SWIG 生成），差异只在两处：
>
> 1. **返回值形态**：C++ 用引用参数回填数据；Python 的返回形态由 SWIG 绑定决定，**逐接口实测**，不按类型推断。
> 2. **少数接口在 Python 中不可直接调用**（绑定缺陷），页面内已逐个标注。

::: warning 本页接口当前 Python SDK 未提供

本页 4 个接口在 `nrc_interface`（Linux / Windows 包均已核对）中**均无同名定义**，Python 侧调用会抛 `AttributeError`。本篇保留 C++ 语义说明用于对接参考，**实现请使用 C++ SDK**；如需 Python 支持请联系纳博特评估排期。

:::
