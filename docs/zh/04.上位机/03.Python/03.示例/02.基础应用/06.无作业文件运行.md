# 6. 无作业文件运行

本期介绍在不新建作业文件的前提下，直接切换到远程模式下发运动指令，并在结束后把机器人恢复到原来的模式。

远程模式（Remote）是上位机直接控制机器人的工作模式。与示教模式不同，远程模式下上位机可以连续下发运动指令，适合由外部程序驱动的场景。「无作业文件运行」指不依赖控制器侧的作业文件，运动指令由上位机直接下发。

::: danger ⚠️ 安全警告

- 运行前确认机器人周围无人员和障碍物
- 首次运行请使用低速
- 建议先在仿真环境中验证，再上真机
- 随时准备按下急停按钮

:::

## 1、与直接运动指令的区别

| 对比项 | 直接运动指令（第 5 页） | 无作业文件运行（本页） |
| --- | --- | --- |
| 机器人模式 | 示教模式 | 远程模式 |
| 上电要求 | 需在示教模式完成上电 | 复用示教模式上电结果，运行前切远程 |
| 运动前状态检查 | 检查伺服状态 | 额外要求运行状态必须为停止 `0` |
| 模式恢复 | 不需要 | 结束后恢复原始模式 |
| 适用场景 | 单点调试、点位验证 | 上位机持续接管控制 |

## 3、切换远程模式

```python
def ensure_remote_mode(socketFd):
    mode = get_current_mode_value(socketFd)
    if mode == REMOTE_MODE:
        print("当前已经是远程模式")
        return

    for i in range(MODE_SWITCH_RETRY_COUNT):
        result = nrc_interface.set_current_mode(socketFd, REMOTE_MODE)
        if result == 0:
            time.sleep(WAIT_MODE_SWITCH_RETRY)
            current = get_current_mode_value(socketFd)
            if current == REMOTE_MODE:
                print("已切换远程模式")
                return
        ...
```

模式查询接口返回 `[结果码, 模式值]`，取值解包：

```python
def get_current_mode_value(socketFd):
    ret = nrc_interface.get_current_mode(socketFd, 0)
    if ret[0] != 0:
        raise Exception(f"获取当前模式失败,返回值:{ret}")
    return ret[1]
```

## 4、运动前状态检查

远程模式运动有一个硬性前提：机器人必须处于停止状态。若处于暂停或运行状态就下发指令，控制器会拒绝执行：

```python
running_state = get_running_state(socketFd)
print("当前机器人运行状态:", running_state)

if running_state != ROBOT_STOP:
    raise Exception(
        f"机器人当前不是停止状态,"
        f"运行状态:{running_state}"
    )

print("机器人当前处于停止状态")
```

运动结束后还要再检查一次，确认机器人已回到停止状态：

```python
final_state = get_running_state(socketFd)
print("运动完成后机器人运行状态:", final_state)

if final_state != ROBOT_STOP:
    raise Exception(f"运动完成后机器人状态异常:{final_state}")

print("POINT1运动完成")
```

## 5、构造指令并下发

```python
def create_move_cmd(pos, velocity):
    cmd = nrc_interface.MoveCmd()
    for i in range(len(pos)):
        cmd.targetPosValue[i] = pos[i]
    cmd.coord = CARTESIAN_COORD
    cmd.velocity = velocity
    cmd.acc = MOVE_ACC
    cmd.dec = MOVE_DEC
    cmd.isSync = True
    return cmd
```

远程模式下只下发一条 MOVJ，流程比第 5 页更聚焦于模式切换与状态确认：

```python
point = POINTS["POINT1"]
print("目标点:", point["pos"])

check_reachable(socketFd, point["check"], "MOVJ")
print("POINT1点检测通过")

movej(socketFd, point["pos"])
time.sleep(WAIT_QUERY_INTERVAL)
```

## 6、恢复原始模式

程序在切换远程模式之前记录了原模式，结束时恢复，避免影响现场后续操作：

```python
original_mode = get_current_mode_value(socketFd)
print("运动前机器人模式:", original_mode)

ensure_remote_mode(socketFd)
...
if original_mode != REMOTE_MODE:
    check_result(
        nrc_interface.set_current_mode(socketFd, original_mode),
        "恢复原始机器人模式"
    )
    print("机器人模式已恢复:", original_mode)
```

## 7、主流程

```python
def main():
    socketFd = None
    original_mode = None

    try:
        socketFd = connect_robot()
        print("连接成功 socketFd =", socketFd)

        state = get_servo_status(socketFd)
        power_on(socketFd, state)

        running_state = get_running_state(socketFd)
        if running_state != ROBOT_STOP:
            raise Exception(f"机器人当前不是停止状态,运行状态:{running_state}")

        original_mode = get_current_mode_value(socketFd)
        ensure_remote_mode(socketFd)

        point = POINTS["POINT1"]
        check_reachable(socketFd, point["check"], "MOVJ")
        movej(socketFd, point["pos"])

        time.sleep(WAIT_QUERY_INTERVAL)
        wait_move_done(socketFd)
        ...
    finally:
        if socketFd:
            ret = nrc_interface.disconnect_robot(socketFd)
            if ret == 0:
                print("连接关闭")
            else:
                print(f"连接关闭失败,返回值:{ret}")
```

即使发生异常退出，`finally` 中仍会断开连接；但模式恢复写在 `try` 内，异常路径下不会执行——生产环境中建议把模式恢复移到 `finally`。

## 9、常见问题

**切换远程模式失败**

控制器可能被示教器或其他上位机占用，或当前存在未清除的报警。先在示教器确认无报警、无其他连接。

**远程模式下运动指令被拒绝**

运行状态不是停止 `0`。本 Demo 在运动前已做检查，若仍失败，检查是否有其他程序正在控制机器人。

**结束后机器人停在远程模式**

`original_mode` 恢复步骤被异常跳过。把恢复逻辑放进 `finally`，或在示教器手动切回示教模式。
