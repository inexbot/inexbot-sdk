# 2. 伺服状态检测

本期介绍如何查询控制器当前的伺服状态，并按状态给出处理建议。伺服状态是所有运动操作的前置判据：只有确认当前处于就绪或运行状态，才能继续下发运动指令。

Python SDK 中状态查询接口返回 `[结果码, 状态值]` 列表，与 C++ SDK 返回结构体不同，判断时需要先看 `status[0]`。

## 状态含义

| 状态值 | 含义     | 处理建议                       |
| ------ | -------- | ------------------------------ |
| 0      | 伺服停止 | 执行伺服就绪或上电操作         |
| 1      | 伺服就绪 | 可直接发送上电指令             |
| 2      | 伺服报警 | 检查报警信息并清除错误         |
| 3      | 伺服运行 | 已上电，可直接执行运动         |
| 其他   | 未知状态 | 停止操作，检查控制器版本与配置 |

## 1、配置连接与查询参数

```python
# ===== 用户需要修改的部分 =====
ip   = "192.168.3.239"
port = "6001"

# ===== 重试与等待参数 =====
CONNECT_RETRY_COUNT      = 5    # 连接失败后的最大重试次数
WAIT_CONNECT_RETRY       = 1    # 连接失败后的等待时间（秒）
SERVO_STATUS_RETRY_COUNT = 3    # 获取伺服状态的最大重试次数
WAIT_SERVO_STATUS_RETRY  = 0.2  # 获取伺服状态失败后的重试间隔（秒）
WAIT_SHOW                = 2    # 状态显示完成后停留时间，方便查看终端输出（秒）
```

## 2、连接控制器

```python
def check_result(result, name):
    if result != 0:
        raise Exception(f"{name}失败,返回值:{result}")

def connect_robot():
    for i in range(CONNECT_RETRY_COUNT):
        socketFd = nrc_interface.connect_robot(ip, port)
        if socketFd > 0:
            print("机器人连接成功")
            return socketFd
        print(f"第{i+1}次连接失败，等待重试")
        # 连接失败后等待一段时间，避免在控制器尚未准备好时连续快速建立连接
        time.sleep(WAIT_CONNECT_RETRY)
    raise ConnectionError(f"连续{CONNECT_RETRY_COUNT}次连接机器人失败")
```

## 3、查询伺服状态

```python
def get_servo_status(socketFd):
    for i in range(SERVO_STATUS_RETRY_COUNT):
        status = nrc_interface.get_servo_state(socketFd, 0)
        # Python 接口返回列表
        # status[0]：接口执行结果，0 表示本次状态查询成功
        # status[1]：当前伺服状态，只有接口执行成功后该值才作为有效状态使用
        if status[0] == 0:
            return status[1]
        time.sleep(WAIT_SERVO_STATUS_RETRY)
    raise Exception(f"连续{SERVO_STATUS_RETRY_COUNT}次获取伺服状态失败")
```

关键点在于：`status[1]` 只有在 `status[0] == 0` 时才有意义。若查询失败却仍然读取 `status[1]`，可能得到上一周期的旧状态，导致后续判据错误。

## 4、按状态输出处理建议

```python
def show_servo_status(state):
    if state == 0:
        print("当前状态:伺服停止")
        print("处理建议:请执行伺服就绪或上电操作")
    elif state == 1:
        print("当前状态:伺服就绪")
    elif state == 2:
        print("当前状态:伺服报警")
        print("处理建议:请检查报警信息并清除错误")
    elif state == 3:
        print("当前状态:伺服运行中")
    else:
        print("未知伺服状态:", state)
```

## 5、完整执行流程

```python
def main():
    socketFd = None
    try:
        socketFd = connect_robot()
        print("连接成功 socketFd =", socketFd)

        state = get_servo_status(socketFd)
        print("获取伺服状态成功")
        show_servo_status(state)

        wait_show()
        print("Demo执行成功")
    except KeyboardInterrupt:
        print("用户主动终止程序")
    except Exception as e:
        print("Demo执行异常:", e)
    finally:
        if socketFd:
            result = nrc_interface.disconnect_robot(socketFd)
            # 断开连接同样需要检查返回值，确保程序退出前已经正常释放控制器连接
            check_result(result, "断开连接")
            print("连接关闭")
```

## 常见问题

- **返回状态为 2：** 伺服报警，需先 `clear_error` 清错，再重新设置就绪
- **持续查询失败：** 检查连接句柄是否有效，以及控制器是否正常响应；Demo 连续失败 3 次后抛异常退出
- **状态与示教器显示不一致：** 以 `get_servo_state` 返回值为准，必要时重新查询确认
