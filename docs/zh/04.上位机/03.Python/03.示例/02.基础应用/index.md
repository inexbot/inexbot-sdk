## 关键知识点

- **连接流程：** `connect_robot()` → 等待 `get_connection_status() == SUCCESS` → 开始操作；`port` 必须传字符串 `"6001"`
- **Python 返回值：** getter 函数返回 `[结果码, 数据值]` 序列（**实测为 `list`**，判断类型用 `isinstance(x, (tuple, list))`），如 `get_servo_state(fd, status)` → `[0, 3]`
- **上电顺序：** 必须先在示教模式完成上电；非 0 状态先清错，再切就绪，最后上电
- **运动完成判据：** 指令返回 `0` 只代表下发成功，需轮询 `get_robot_running_state` 并连续确认停止
- **模式取值：** `0` 示教、`1` 远程、`2` 运行
- **文件传输：** 除 6001 外还需控制器 TCP 5000 端口可用
