# 进阶应用

Python SDK 进阶示例，收录两类内容：**伺服高级控制**（7000 端口实时下发点位），以及**跨多个模块串起完整闭环的综合示例**（连接 → 上电 → 点动/IO，单文件跑通一次真机流程）。单个接口的独立演示请先看[基础应用](../02.基础应用/index.md)。

> ⚠️ **安全提示：** 本节的运动示例会导致机器人实际运动。请在使用前仔细阅读各页面顶部的安全警告，确保工作空间安全、急停可用。

## 关键知识点

- **7000 端口：** servo_move 需要单独连接控制器 7000 端口，与 6001 端口分开
- **运行模式：** servo_move 需在运行模式下配合含外部点指令的作业文件使用
- **ServoMovePara 参数：** `clearBuffer`（清空缓冲）、`targetMode`（0=独立点/1=连续轨迹）、`coord`（0=关节/1=直角）
- **回调函数：** 使用 `set_receive_error_or_warnning_message_callback()` 注册错误处理，回调内不能做耗时操作
- **点动保持式重发：** 点动指令需按固定周期（示例 50 ms）持续重发，停止发送即停止运动
- **安全：** servo_move 会导致机器人实际运动，请先在仿真或低速下测试
