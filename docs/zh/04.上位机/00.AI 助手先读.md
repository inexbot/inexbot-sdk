# AI 助手 / 自动化工具：先读这里

> 如果你是 AI 助手、自动化工具，或用 AI 生成上位机二次开发程序——**先读下面三页，再动手**。

- [Agent 开发指引](../13.Agent%20开发指引.md)：任务到文档的索引、推荐生成流程、常见避坑
- [生成前信息采集清单](../15.生成前信息采集清单.md)：生成前必须逐项向客户确认（语言 / 编译环境 / 版本 / 真机与 IP、端口）
- [编译与验证指南](../14.编译与验证指南.md)：没有真实控制器时的编译级 / 仿真级验证方法

**本目录（04.上位机）即默认开发方式的主通道**——按客户语言进入 [C++](./01.C++/02.接口/index.md)、[C#](./02.CSharp/02.接口/index.md)、[Python](./03.Python/02.接口/index.md) 接口文档；示例从 [C++ 基础应用](./01.C++/03.示例/02.基础应用/index.md) 看起。

机器可读：`/llms.txt`（索引）与 `/llms-full.txt`（全文）；本站每页把 `.html` 换成 `.md` 即为纯文本版。

**两条硬性约定**：生成前先问清楚（不要默认假设）；函数名以站内接口页与真实头文件为准（不要凭记忆书写）。
