# 错误码表

C# 与 C++ 使用**同一套**错误码，不单独维护：

| 体系 | 说明 | 入口 |
| ---- | ---- | ---- |
| 上位机 SDK 返回值 | `Result`（`0`、`-1` ~ `-6`），C# 封装语义与 C++ 一致 | [C++ · 错误码表](../../01.C++/04.参考/错误码表.md) |
| 控制器上报消息码 | 控制器运行期主动上报的 4~5 位十进制码，C++ / C# / Python 与控制器 SDK 共用 | [控制器报错码](../../../06.控制器/04.参考/控制器报错码/index.md) |

判断原则与 C++ 相同：接口返回 `SUCCESS` 只说明本次调用被接受，不代表控制器没有上报消息，**两套要分开判断**。
