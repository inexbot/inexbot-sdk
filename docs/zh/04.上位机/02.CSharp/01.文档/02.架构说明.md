# 架构说明

C# SDK 是对 C++ SDK 的托管封装，`Csharp_api/` 目录包含 SWIG 自动生成的 C# 接口。

## 托管接口与原生库

| 层次 | 文件 | 说明 |
|------|------|------|
| 托管接口 | `Csharp_api.dll` | C# 可直接引用的托管程序集 |
| 原生库 | `nrc_host.dll` | C++ 底层通信库（**必须随程序分发**） |

`Csharp_api.dll` 通过 P/Invoke 调用 `nrc_host.dll`。运行时**两个文件都必须在输出目录中**。

## SDK 组成

```text
Csharp_api/
├── Csharp_api.dll              ← 托管程序集
├── nrc_host.dll                ← C++ 原生动态库
├── nrc_interface.cs           ← 主接口类（静态方法）
├── nrc_interfacePINVOKE.cs    ← P/Invoke 底层调用
├── MoveCmd.cs                 ← 运动指令参数
├── ServoMovePara.cs           ← 伺服运动参数
├── ToolParam.cs               ← 工具手参数
├── RobotDHParam.cs            ← DH 参数
└── ...                        ← 其他数据结构与枚举
```

## 调用链

```text
C# 代码 → Csharp_api.dll (托管) → P/Invoke → nrc_host.dll (原生) → TCP Socket → 控制器
```

所有 C# 接口与 C++ **同名同参**，可对照 [C++ API 参考](../../01.C++/02.接口/index.md) 了解详细参数说明。

## 类型映射

| C++ | C# |
|-----|-----|
| `SOCKETFD` (int) | `int` |
| `std::string` | `string` |
| `std::vector<double>` | `VectorDouble` |
| `std::vector<vector<double>>` | `VectorVectorDouble` |
