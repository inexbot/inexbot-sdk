# 渐入式教程

从零搭建 C# Windows 窗体应用项目，引入 SDK 并验证连接。

## 前提条件

已安装 Visual Studio 2022 和 .NET 8.0 开发环境。

## 教程目录

- [初始化项目](./01.环境搭建.md) — 完整步骤：创建项目、导入 SDK、引用动态库、验证连接

## 下一步

完成首次连接测试后，请浏览[接口示例](../02.接口/index.md)了解更多 API 用法。

## 通用约定（与语言无关）

返回值判定、端口与句柄、单位口径、调用前后自检，属**控制器与 SDK 的通用约定**，C# 调用同样适用，统一维护在 C++ 接口说明的首页：[C++ SDK 接口说明 · 通用约定速查](../../01.C++/02.接口/index.md)。
