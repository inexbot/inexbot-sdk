# 环境搭建

C++ SDK 支持三种开发环境，请根据你的编译工具链选择：

| 环境 | 工具链 | 平台 | 教程 |
|------|--------|------|------|
| MinGW | GCC + Qt Creator | Windows | [MinGW 环境](./01.MinGW%20环境.md) |
| MSVC | Visual Studio 2019+ | Windows | [MSVC 环境](./02.MSVC%20环境.md) |
| Linux | GCC + Makefile | Linux | [Linux 环境](./03.Linux%20环境.md) |

> **重要：** MinGW 编译的库与 MSVC 编译的库**不能混用**。下载 SDK 时请选择与你编译器匹配的版本。
