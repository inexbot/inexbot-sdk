# 示教器开发文档

纳博特示教器（T30 / T31 / T40 系列）是 ARM + Qt 的现场操作端，通过以太网与控制器通讯。本分区面向**在示教器上做二次开发**（自定义页面、按键、界面扩展）的读者；只想知道怎么操作示教器的，请查随机的操作手册。

## 需要注意

- 示教器与控制器之间是**独立于上位机 SDK 的另一条通道**（6000 端口方向），不要用上位机的 6001 口去套示教器接口。
- 页面上看到的按钮位置随**实体版与 PC 版**不同，按手册找不到按键时先确认你用的是哪一版。
