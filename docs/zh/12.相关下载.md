## Python SDK

::: warning Python 版本必须匹配（官方库按版本预编译，不匹配无法加载）
官方预编译的 Python 扩展库**仅支持**：**Windows = Python 3.10（64 位）**、**Linux = Python 3.8**。
使用其他版本（如 3.11 / 3.12）时，`import nrc_interface` 会报 `ImportError`（或运行时崩溃）。

建议单独安装匹配版本：Windows 用 `uv python install 3.10`（或 pyenv-win 安装 3.10 x64）；Linux 用 `uv python install 3.8`（或 `pyenv install 3.8`）。
:::

| 平台    | 架构 | Python 版本 | SDK 版本   | 本地库         | 下载                                                    |
| ------- | ---- | ----------- | ---------- | -------------- | ------------------------------------------------------- |
| Windows | x64  | 3.10        | 待研发确认 | `nrc_host.pyd` | [资源仓库](https://cnb.cool/inexbot/inexbot-sdk-devkit) |
| Linux   | x64  | 3.8         | 待研发确认 | `_nrc_host.so` | [资源仓库](https://cnb.cool/inexbot/inexbot-sdk-devkit) |

> **说明：**
>
> - Python SDK 通过 C 扩展调用本地库实现控制器通信。
> - 本地库必须与 Python 版本和架构严格匹配，混用会导致 `ImportError` 或段错误。
> - 官方扩展库按解释器版本预编译：**Windows 为 Python 3.10 x64，Linux 为 Python 3.8**；请使用对应版本的 Python——其他版本无法直接加载现成扩展库。
> - 安装方式：将 SDK 包解压后，确保 `nrc_interface.py` 和对应本地库在同一目录，或在 Python 路径中引用。

**快速开始：** [Python 渐入式教程](./04.上位机/03.Python/01.文档/index.md)
