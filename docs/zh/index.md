# 纳博特 SDK 开发文档

欢迎来到纳博特机器人二次开发文档。无论你是在开发上位机应用、集成通信协议，还是定制控制器行为，这里都能找到对应的指南和 API 参考。

::: tip 用 AI 助手（Agent）开发？

- **先读两页**：[Agent 开发指引](./13.Agent%20开发指引.md)（任务索引 / 生成流程 / 避坑速查）与 [生成前信息采集清单](./15.生成前信息采集清单.md)（生成前逐项问客户，不要默认假设）
- **机器可读入口**：`/llms.txt`（文档索引）· `/llms-full.txt`（全文合集）；任意页面把网址中的 `.html` 换成 `.md` 即纯文本版
- **Agent 套件**（技能 / 通用规则 / 避坑清单 / 三级自检）—— 见[《Agent 开发指引》](./13.Agent%20开发指引.md)第 7 节；在 SDK 资源仓库里开发时**克隆即自带技能（零安装）**

:::

## 版本提示

- **RTL-24.03** — 当前主流出货版本，功能更全面。进行 bug 修复和关键功能合入。
- 后续版本（如 2501）尚未稳定，暂未开放 SDK 文档。

> SDK 版本需与控制器固件版本匹配，具体参见[版本与兼容性](./版本与兼容性.md)和[下载页](./12.相关下载.md)。

## 使用 AI 助手（Agent）辅助开发

如果你使用 AI 助手（Agent）辅助二次开发，请先阅读 [Agent 开发指引](./13.Agent%20开发指引.md)：包含任务到文档的索引、推荐生成流程与常见避坑；生成前先按[生成前信息采集清单](./15.生成前信息采集清单.md)逐项确认（语言 / 环境 / 版本 / 真机与 IP）；无硬件时的验证方法见 [编译与验证指南](./14.编译与验证指南.md)。
